## 추가 요청 반영(같은 날)

- 업적도 상단 바 탭으로 뺐다: `펫룸 · 뽑기 · 합성 · 도감 · 정보 · 업적 · 전투 ↗`. 정보 창 안의 `정보 · 업적` 탭을 지우고 화면 이름을 둔다. 정보 창이 `petto:current`로 지금 화면을 알려 상단 바의 금색 탭이 따라간다. 받을 보상의 점은 `업적` 탭으로 옮겼다.
- 실화면: 펫룸에서 `업적` 탭 → 같은 자리에서 업적, 업적 → 정보 → 설정(⚙)으로 옮길 때 지금 탭이 업적 → 정보 → 정보, 탭 일곱 개와 칩·닫기가 640 안에 넘치지 않음(닫기 오른쪽 끝 634). 패널 자체 시험 실패 0.
- 전투 창 `펫룸` 버튼이 여전히 눌리지 않는다는 보고: 창 끌기 영역이 버튼을 덮고 있었다(별도 커밋 `07cadda`). 네이티브 끌기 판정은 z-index 와 따로라, 스크립트 `click()`으로는 이 문제가 보이지 않는다.

## 추가 요청 반영 2(같은 날)

- 전투 창의 `펫룸` 버튼을 뺐다(요청자 결정: 항상 위인 투명 창에서 다른 창을 여는 UX가 어색하다). 전투 창은 펫 정보 한 줄만 남기고 `main`과 같은 끌기 영역·닫기로 돌아갔다. 펫룸이 전투 창 아래에 깔리지 않게 하는 수정(`625f9c5`)은 메뉴·상단 바로 연 640 창에도 쓰이므로 남긴다.
- 설정을 상단 바로 올렸다: 화면 탭 줄 오른쪽에 떨어뜨린 `⚙ 설정`. 정보 창 바닥의 `⚙`와 설정의 `←`를 지웠다. 정보 창이 지금 화면을 알려 설정 화면에서는 `⚙ 설정`이 금색이다.
- 확인: 설정 탭 → 같은 창에서 설정, 지금 탭 `settings`, 서브탭 다섯 개. 전투 창에 `.window-room` 없음. 패널 자체 시험 `상단 바 지금 탭 설정·업적·정보 알림 정상`, 실패 0. 검증 스크립트 657/657, 앱 테스트 114/114.
