# 전투 간소화와 실시간 투명도 수정

## Track and Seed

Standard. 요청자가 2026-10-07 제자리 기본 공격을 유지하는 간소화 안을 선택했다.
[간소화 명세](../.harness/specs/features/2026-10-07-battle-simple-animation.md)와
직접 요청한 실시간 투명도·전투 펫 제외를 반영한
[표시 설정 명세](../.harness/specs/features/2026-10-07-battle-display-settings.md)를 Seed로 사용한다.
성공 기준은 간소화에서 공격 유지·이동 및 큰 효과 제거, 드래그 중 투명도 반영,
펫의 불투명 유지와 테두리 투명화다. XP·저장 형식·다른 창 변경은 범위 밖이다.

## Explorer

기존 OFF는 자동 공격을 중지하고 모든 CSS 애니메이션을 정지했다.
Arena에는 움직임을 줄여 제자리에서 싸우는 경로가 있으므로 기본 공격 프로필과 결합한다.
현재 body의 투명도는 전투 펫까지 영향을 주므로 환경과 펫의 공통 조상에 적용할 수 없다.
환경·HUD·메뉴·독립 효과는 root의 직접 자식이며 펫은 별도의 자식이다.
설정 슬라이더는 change에서만 저장했고 설정 push마다 다시 그려졌다.

## Planner

1. 간소화에서 기본 공격 프로필과 기존 위치 고정 경로를 사용한다.
2. 기존 OFF 값을 간소화로 해석하고 설정에 의미를 안내한다.
3. 투명도를 환경과 독립 효과에 적용하고 외곽선·그림자의 alpha를 함께 조절한다.
4. 전투 펫은 투명도 대상에서 제외한다.
5. input에서 저장을 순서대로 요청하고 드래그 중 UI 재생성을 억제한다.
6. 전 종류의 위치 고정·공격 유지 테스트와 Electron의 실제 픽셀·슬라이더 동작을 확인한다.

## Implementer

간소화는 Arena의 기본 프로필과 reduced motion 경로를 사용한다.
공격 스프라이트는 계속 표시하고, 적은 제자리에서 작은 압축으로 공격을 표현한다.
종별 광역 효과·투사체·추격·카메라 이동은 제거하며 응원 펫은 정지 상태로 유지한다.
기본 모드와 XP 계산은 유지한다. 저장된 false는 간소화로 이어받는다.

환경은 공유 CSS 투명도 값으로 표시하며 전투 펫과 공통 조상은 불투명하게 유지한다.
외곽선과 창 그림자는 같은 값의 alpha를 사용한다.
독립 캔버스와 말풍선의 내부 opacity도 해당 값으로 반영해 누락·중첩을 피한다.
설정 슬라이더는 input마다 저장 요청을 순서대로 처리하며 현재 백분율을 바로 갱신한다.
드래그 중 설정 push로 슬라이더를 교체하지 않고 조작 종료 후 저장 상태로 다시 그린다.

## Verifier

- display-settings 집중 테스트: 저장 실패·복구, 간소화 상태의 실제 XP 진행,
  6종에서 8초 동안 제자리 공격·반격 유지 및 카메라 고정 통과.
- `npm run typecheck`, `npm run build:ui --workspace @pet/battle` 통과.
- `apps/desktop/test/battle-display.electron.cjs`: 실제 설정 탭의 input 이벤트만으로
  실시간 반영, 드래그 중 요소 유지, 간소화의 기본 공격 및 위치 고정,
  양방향 설정 갱신과 복귀를 확인한다. 35% 캡처에서 펫 alpha 255와 테두리 alpha 95 이하,
  0%에서 테두리 소멸과 펫 표시 유지를 확인한다.
- 공유 gate는 `bash .harness/scripts/verify-electron.sh`이며 최종 결과는 작업 응답에 기록한다.
