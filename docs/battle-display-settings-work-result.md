# 전투 표시 설정 작업 결과

## Track and Seed

Standard. 2026-10-07 요청자가
[전투 표시 설정 명세](../.harness/specs/features/2026-10-07-battle-display-settings.md)를 승인했다.
알림과 기타 사이에 전투 탭을 추가하고, 애니메이션 OFF에서 진행을 유지하며,
투명도가 외곽선까지 적용되고 재실행 후 복원되는 것이 성공 기준이다.
XP·성장·전투 난이도와 다른 창의 투명도는 범위 밖이다.

## Explorer

설정 UI는 `pet-meta/ui/panel.js`, 설정 조회와 변경은 meta 핸들러가 소유한다.
설정 저장은 meta 스냅샷과 공통 DB의 `meta_settings`를 사용한다.
전투는 런타임 내부의 표시 투명도를 사용해 재시작 시 복원하지 않았으며,
렌더러가 내부 요소별로 투명도를 적용해 외곽선과 일부 요소가 남았다.
실제 진행은 XP 스냅샷에서 계산하므로 시각 애니메이션과 독립적으로 유지할 수 있다.

## Planner

1. 설정 검증·저장 실패의 실패 테스트를 추가한다.
2. 기존 설정 모델과 저장에 두 표시 값을 추가하고 옛 저장본을 기본값으로 복원한다.
3. battle 소유 설정 Port를 런타임에 주입하고 meta가 앱 조립을 통해 구현한다.
4. 설정 탭을 추가하고 양쪽 투명도 변경을 같은 저장값에 연결한다.
5. 움직임·효과를 끄되 진행은 유지하고, body에 투명도를 한 번 적용한다.
6. 계약·복원·실패 테스트, 실제 SQLite migration과 Electron UI를 검증한다.

## Implementer

설정 핸들러 테스트는 새 기본값이 없어 먼저 실패했다.
기존 meta migration은 그대로 두고 v3에서 설정 테이블을 데이터 보존과 함께 확장했다.
애니메이션 기본값은 ON, 투명도 기본값은 100이며 입력 범위는 0~100 정수다.
설정 저장 실패는 메모리 변경을 되돌리고 오류를 호출자에게 전달한다.
전투 설정 Port는 읽기와 투명도 저장만 제공하며 저장 완료 후 UI에 반영한다.
입력과 poll은 순서대로 처리하고 실패 뒤에도 다음 조회가 정상 동작한다.

전투 시각 모델은 OFF에서 자동·수동 공격과 효과를 중지하고 실제 HP·stage는 갱신한다.
전환 시 모션 키가 바뀌어 기존 공격 및 피격 연출을 정리한다.
투명도는 body에 적용해 외곽선·그림자·내용에 동일하게 적용하며 중첩 적용을 제거했다.
픽셀 스타일 슬라이더와 현재 백분율, 스위치 및 접근성 이름을 제공한다.

## Verifier

- 집중 테스트: 설정 입력 검증, 저장 실패 복구, 양쪽 값 동기화, 재진입 복원,
  OFF 상태에서 실제 저장 XP 증가 후 stage 진행, 옛 스냅샷의 기본값을 확인했다.
- `npm run typecheck` 및 `npm run build:ui --workspace @pet/battle` 통과.
- Electron의 Node 런타임으로 `apps/desktop/test/meta-repository.test.cjs` 실행:
  migration과 이전 설정 보존, 새 설정 재시작 복원 등 10개 통과.
- 실제 Electron에서 `apps/desktop/test/battle-display.electron.cjs` 실행:
  탭 순서, 토글, 움직임 정지, 양방향 투명도, 0%에서 설정을 통한 복구 통과.
  offscreen 캡처에서 35% 투명도의 전체 픽셀 alpha가 95 이하인지 확인해
  외곽선만 불투명하게 남지 않는 것을 검증했다. 설정 탭 캡처도 시각 검토했다.
- 공유 gate는 `bash .harness/scripts/verify-electron.sh`다. 최초 실행에서 과거의
  요소별 투명도 방식을 강제하던 계약 테스트 하나가 실패해 새 동작으로 갱신했다.
  최종 gate의 최신 결과는 작업 응답에 기록한다.
