# Feature specification: 전투 연출 간소화

## Status

Approved

## Owner

요청자

## Problem and user outcome

애니메이션 OFF에서 완전히 정지하는 전투가 생동감 없이 느껴진다.
방해되는 큰 움직임은 줄이면서 펫이 전투 중임을 기본 공격 동작으로 전달한다.

## Scope

기존 ON/OFF를 기본 연출과 간소화 연출로 개선하는 안을 제안한다.

## Non-goals

전투·XP·성장 규칙, 신규 스프라이트 제작, 투명도 규칙 변경.

## Domain rules

- 기본 모드는 현재의 종별 전투 연출을 유지한다.
- 간소화 모드는 펫과 적의 위치를 고정하고 기본 공격 스프라이트를 표시한다.
- 추격·후퇴·화면 이동·카메라 추적·큰 투사체·광역 효과는 생략한다.
- 적 HP와 스테이지 진행은 현재 상태를 계속 반영한다.
- 모드 변경은 현재 전투에서 즉시 반영되며 이전 연출을 몰아서 재생하지 않는다.
- 기존 ON은 기본, OFF는 간소화로 해석해 사용자 설정을 유지한다.
- 설정에서는 간소화의 의미를 명확히 안내한다.

## Acceptance criteria

- 간소화에서 전투 펫은 기본 공격 동작을 하며 완전히 정지하지 않는다.
- 펫과 적의 위치 및 카메라는 변하지 않고 큰 효과는 나타나지 않는다.
- 간소화에서도 HP와 스테이지가 진행하며 기본 모드로 정상 복귀한다.
- 펫 종류·진화 단계, 재시작 및 진행 전환에도 같은 규칙을 유지한다.

## Edge and error cases

활성 펫이 없으면 기존 빈 상태를 유지한다. 공격 자산이 없는 경우 기존 대기 이미지를 사용한다.

## API and data impact

기존 설정값의 의미를 기본/간소화로 변경한다. 상세 표시 방식은 승인 후 계획한다.

## Open questions
