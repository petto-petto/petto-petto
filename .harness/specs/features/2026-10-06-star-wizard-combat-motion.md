# Feature specification: 별빛마법사 전투 모션

## Status

Approved (요청자 승인, 2026-10-06)

## Owner

전투 담당자(srkim0917)

## Problem and user outcome

별빛마법사(`star_wizard`)는 EPIC 펫이지만 공통 공격 모션을 사용한다. 단계별 시전 동작과 전투 화면 전체의 별자리·유성우, 마지막 큰 유성으로 EPIC의 강한 마법 공격을 표현한다.

## Scope

- 집중 → 시전·부유 → 전장 유성우 → 큰 유성 → 폭발 → 착지·복귀의 약 3초짜리 모션.
- 전투 화면을 보랏빛으로 어둡게 하고, 하늘의 별자리 마법진과 바닥의 주문 고리, 화면 전역의 유성을 표시한다.
- 1단계는 별빛 지팡이를 소환하고, 2단계는 기존 지팡이를 들어 올린다. 3단계는 여러 갈래 하단을 펼쳐 몸과 별빛 구슬로 시전한다.
- 1·2단계의 32×32와 3단계의 48×48 프레임을 각각 사용한다. 공유 원본 PNG는 수정하지 않는다.

## Non-goals

- 다른 펫의 모션, 실제 피해량, XP·재화 지급 또는 적 진행 규칙 변경.
- 전투 창 밖의 화면 효과 또는 공개 Port·IPC·DB 변경.

## Domain rules

1. 준비 때 몸을 천천히 한 번 기울이고, 주문을 발동하며 떠오른 뒤 원래 자세로 복귀한다. 3단계는 여러 다리처럼 보이는 하단을 지지 자세로 펼치며 사람형 동작을 강요하지 않는다.
2. 모든 단계에서 유성우가 전투 화면의 좌우와 위아래에 분포한다. 진화할수록 유성 수·마법진·폭발 고리가 풍성해지며 작은 유성은 최대 24개로 제한한다.
3. 작은 유성과 별빛은 장식이다. 타격 신호는 마지막 큰 유성이 적에게 도달할 때 한 번만 발생한다.
4. 펫 얼굴, HP바, 닫기 버튼과 조작 메뉴는 마법 효과 중에도 보이고 사용할 수 있다. 효과층은 입력을 가로채지 않는다.
5. 공격 중 기본 이미지 파일을 교체하지 않는다. 합성 프레임을 준비하지 못하면 기존 펫 이미지를 유지한다. 48px 진화 형태를 32px로 자르지 않는다.
6. STOP, 숨김, 펫·단계 변경 또는 전투 종료는 유성우·화면 어둡기·부유 자세를 정리한다. 모션 감소에서는 장식을 생략하면서 단일 타격 신호를 유지한다.

## Acceptance criteria

- **WIZ-1:** 세 진화 단계의 시전 동작과 32/48px 전체 형태가 실제 공유 펫 스프라이트로 표시된다.
- **WIZ-2:** 유성우는 전투 화면의 네 가로 구간에 모두 나타나며, 마지막 큰 유성과 넓은 폭발·바닥 파동으로 마무리된다.
- **WIZ-3:** 수동·자동 공격에서 타격은 한 번이고 얼굴·HP바·조작 UI가 유지되며 HP·XP에 추가 쓰기를 만들지 않는다.
- **WIZ-4:** 화면 지연에도 큰 유성이 명중 전에 표시되고, 공격 종료·STOP 뒤 두 마법 효과층과 부유 자세가 정리된다.
- **WIZ-5:** 모션 감소에서도 펫이 표시되고 단일 타격을 유지한다.

## API and data impact

전투 패키지의 종별 시전·스프라이트 합성과 전용 화면 효과만 추가한다. 공개 계약, 저장 형식, 다른 패키지와 공유 에셋은 변경하지 않는다.
