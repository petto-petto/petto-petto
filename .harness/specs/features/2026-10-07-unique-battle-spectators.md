# Feature specification: 중복 없는 전투 응원 펫

## Status

Approved

## Owner

요청자

## Problem and user outcome

펫룸에 같은 모습의 개체가 여러 마리 있어도 전투 배경에는 서로 다른 모습의 응원 펫이 나온다.

## Scope

펫룸 목록에서 전투 응원 펫을 선택하는 규칙을 수정한다.

## Non-goals

응원 위치, 애니메이션, 보유 펫, 성장 데이터 및 전투 규칙 변경.

## Domain rules

- 같은 종류와 같은 진화 단계의 펫은 응원에 최대 한 마리만 등장한다.
- 현재 오버레이 펫과 같은 종류·진화 단계의 모든 개체를 제외한다.
- 같은 종류라도 진화 단계가 다르면 등장할 수 있다. 오버레이가 1단계이면 0단계와 2단계는 허용한다.
- 기존 무작위 선택과 최대 세 마리 제한을 유지한다.
- 후보가 부족하면 가능한 수만 표시하며 중복으로 빈자리를 채우지 않는다.
- 활성 펫, 목록 또는 진화 단계가 바뀌면 새 규칙으로 후보를 갱신한다.

## Acceptance criteria

- 같은 종류·단계의 여러 개체에서 응원은 하나만 선택됨을 테스트한다.
- 활성 개체뿐 아니라 같은 종류·단계의 다른 개체도 제외됨을 테스트한다.
- 다른 진화 단계의 같은 종류는 허용됨을 테스트한다.
- 후보 부족 및 성장 상태 변경 후에도 중복·제외 규칙을 만족함을 테스트한다.

## Edge and error cases

활성 펫이 없거나 유효한 후보가 없으면 응원 펫은 없다.

## API and data impact

저장 형식 및 외부 계약 변경 없음.
