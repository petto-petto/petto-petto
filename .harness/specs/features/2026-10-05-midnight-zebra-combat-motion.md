# Feature specification: 미드나잇얼룩말 전투 모션

## Status

Approved (요청자 승인, 2026-10-05)

## Owner

전투 담당자(srkim0917)

## Problem and user outcome

현재 미드나잇얼룩말 전투 스프라이트는 정면을 보고 있다. 적을 향해 옆으로 달리는 동작은 옆면 또는 3/4 방향 에셋 없이 자연스럽게 표현하기 어렵다. 사용자는 정면 시점을 유지하면서 얼룩말의 줄무늬가 드러나는 RARE 전용 공격 모션을 원한다.

## Scope

- 정면을 유지하며 왼쪽 앞다리만 두 번 구른 뒤 화면 앞쪽으로 짧게 다가왔다 복귀하고, 적을 향해 초승달형 줄무늬 충격파를 보내는 미드나잇얼룩말 전용 공격 모션.
- 기존 stage 1~3 기본 스프라이트와 전투 시계를 활용한다.
- 진화 단계에 따라 충격파의 폭·줄무늬·마무리 파편을 단계적으로 확장한다.
- 정수 픽셀 단위로 효과를 그리며, 화면 앞쪽 접근이 끝난 뒤 단일 충격 효과를 표시한다.

## Non-goals

- 옆면/3/4 방향 스프라이트 제작 또는 캐릭터의 좌우 회전·질주.
- 전투 피해량, 공격 판정 횟수, 적 진행, XP·재화 지급 규칙 변경.
- 다른 종의 공격 모션 변경.

## Domain rules

1. 얼룩말은 정면을 유지한다. 발구름 동안에는 몸통 픽셀과 자세가 고정되며 다리만 움직인다. 발구름 이후에는 작은 일회성 확대와 화면 아래쪽 이동으로 관찰자에게 다가오는 깊이감을 표현하고 원래 위치로 복귀한다.
2. 화면 오른쪽에 보이는 얼룩말의 왼쪽 앞발굽을 두 번 들고 구른 뒤, 화면 앞쪽 접근·복귀를 거쳐 초승달 파동을 보낸다. 두 착지는 충분한 간격과 지면에 딛는 구간을 두어 구분되며, 공격 타격 신호는 접근·복귀 뒤 한 번만 발생한다.
3. 충격파는 얼룩말의 밝고 어두운 줄무늬와 에셋의 제한된 강조색을 사용한다.
4. 진화 단계는 연출의 외형만 바꾸며 공격 규칙은 바꾸지 않는다.
5. 모션 감소 설정, 공격 취소, 펫 선택 변경, STOP/START에서 효과가 남거나 반복 타격하지 않는다.

## Acceptance criteria

- **ZEB-1:** 세 진화 단계에서 기존 미드나잇얼룩말 스프라이트가 표시되며 공격 중 사라지지 않는다.
- **ZEB-2:** 왼쪽 앞다리의 두 번 구르기 → 화면 앞쪽 접근·복귀 → 초승달 파동의 순서로 재생된다. 발구름 중 몸통 픽셀은 고정된다.
- **ZEB-3:** 공격 모션의 타격 신호는 한 번이며 실제 피해량·XP·적 전환 결과가 유지된다.
- **ZEB-4:** stage 1에서 stage 3으로 갈수록 충격파 표현이 단계적으로 풍부해지고 과도한 화면 가림은 없다.
- **ZEB-5:** 모션 감소 및 공격 취소·선택 변경·STOP/START 뒤에 충격파 잔상이 남지 않는다.

## Edge and error cases

- 공격 중 진화 단계나 선택 펫이 바뀌면 이전 공격 효과가 새 펫에 남지 않는다.
- 충격파 렌더링이 지연되거나 프레임이 건너뛰어도 추가 타격을 만들지 않는다.
- 모션 감소 환경에서는 타격과 진행 결과를 유지하면서 장식 효과를 줄인다.

## API and data impact

전투 패키지의 종별 모션 프로필과 시각 효과만 변경한다. 공개 Port, IPC, DB, 저장 형식은 변경하지 않는다.

## Open questions

없음. 정면 시점, 왼발의 두 번 구르기, 초승달 충격파 방향은 요청자가 지정했다.
