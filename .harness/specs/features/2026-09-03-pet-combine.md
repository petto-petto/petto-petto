# Feature specification: 펫 합성 프로토타입

## Status

Approved (요청자 승인, 2026-09-03)

## Owner

동우 (요청자)

## Problem and user outcome

사용자는 보유 펫 카드 10장을 같은 등급끼리 합성해 한 단계 높은 등급의 stage 1 펫을
얻고 싶다. 프로토타입은 실제 인벤토리 대신 충분한 시작 카드와 Token을 제공하지만,
성공 시 재료·비용을 실제처럼 차감해 합성 흐름과 오류 상태를 확인할 수 있어야 한다.

## Scope

- `COMMON 합성`과 `RARE 합성` 탭을 제공한다.
- 각 종의 common/rare 펫은 시작 시 30장씩 제공한다.
- 탭 진입 시 표시 순서대로 해당 등급 카드 10장을 자동 선택한다.
- 선택한 카드는 제거할 수 있고, 같은 탭/등급의 다른 카드를 직접 추가해 10장을 채울 수 있다.
- common 10장 합성은 30,000 Token을 소모해 rare stage 1 한 마리를 균등 랜덤으로 지급한다.
- rare 10장 합성은 100,000 Token을 소모해 epic stage 1 한 마리를 균등 랜덤으로 지급한다.
- 시작 Token은 200,000이다.
- 합성 성공 시 선택 재료 10장과 비용을 차감하고, 결과를 표시한다.
- epic은 상위 등급이 없으므로 합성 탭/대상으로 제공하지 않는다.

## Non-goals

- 영속 인벤토리, 서버 동기화, 실제 계정 데이터
- epic 이상의 등급, 합성 실패 확률, 보너스 규칙
- 뽑기와 합성 사이의 공유 재화/인벤토리 연동

## Domain rules

1. 합성 재료는 정확히 10장이어야 한다.
2. 모든 재료는 선택한 탭과 같은 등급이어야 한다.
3. 같은 종의 카드를 여러 장 재료로 선택할 수 있다.
4. 목표 등급의 결과 종은 균등 랜덤으로 선택한다.
5. 결과 펫은 언제나 stage 1이다.
6. 검증 실패 시 재료·Token·결과는 변하지 않는다.
7. 합성 버튼은 항상 누를 수 있으며, 검증 실패 시 해당 오류를 메시지로 표시한다.

## Acceptance criteria

- common 탭은 common 카드만, rare 탭은 rare 카드만 재료로 선택할 수 있다.
- 탭 진입 시 표시 순서대로 10장이 자동 선택된다.
- 자동 선택된 카드 중 일부를 제거하고 같은 등급의 다른 카드로 교체할 수 있다.
- 10장의 common/rare 카드와 충분한 Token으로 각각 rare/epic stage 1 결과를 얻는다.
- 결과 종은 목표 등급 풀에서 균등 랜덤 선택 함수로 결정된다.
- 재료가 10장이 아니거나 Token이 부족해도 버튼을 누르면 구체적 오류 메시지가 표시되고 상태는 차감되지 않는다.
- 200,000 Token에서는 rare 합성을 두 번 성공시킨 후 세 번째 시도에서 Token 부족 메시지를 확인할 수 있다.

## Edge and error cases

- 카드 수량이 0이면 추가할 수 없고, 수량 부족 메시지를 보인다.
- 결과 등급 풀에 종이 없으면 합성하지 않고 구성 오류 메시지를 보인다.
- 합성 중에는 중복 실행을 막는다.

## API and data impact

새 `@pet/combine` 순수 도메인 상태와 프로토타입 UI를 추가한다. 영속 포맷과 외부 API는 없다.
