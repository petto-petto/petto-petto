# Feature specification: 볼주머니햄 전투 모션

## Status

Approved (요청자 승인, 2026-10-06)

## Owner

전투 담당자(srkim0917)

## Problem and user outcome

볼주머니햄(`cheek_hamster`)은 RARE 펫이지만 공통 공격 모션을 사용한다. 정면의 큰 볼을 활용한 준비 동작과 먹이탄 발사로 종의 특징을 드러내고, 금빛 탄환과 민트색 잔상으로 RARE 전용 공격을 구분한다.

## Scope

- 웅크리며 양쪽 볼을 부풀린 뒤 짧게 뛰어올라 공중에서 큰 먹이탄 한 발을 발사한다. 발사 순간 뒤로 밀리는 반동을 보이고 탄력 있게 착지한다.
- 충전 중 금빛·민트색 알갱이가 모이고, 먹이탄은 회전 고리와 긴 잔상을 남기며 적에게 날아가 두 겹의 고리와 별 모양 파편으로 터진다. 공격 뒤 볼과 몸의 자세는 원래 상태로 돌아온다.
- 전체 모션은 약 1.2초이며 기존 stage 1~3 기본 스프라이트와 전투 시계를 사용한다.
- 진화할수록 탄환 외형, 민트색 잔상과 명중 파편이 풍성해진다.

## Non-goals

- 옆면 스프라이트, 장시간 질주 또는 반복적인 몸 전체 떨림.
- 실제 피해량, XP·재화 지급, 적 진행과 저장 형식의 변경.
- 다른 종의 전투 모션 또는 공유 펫 에셋 변경.

## Domain rules

1. 웅크리며 볼 충전 → 도약·머금기 → 공중에서 단일 발사·반동 → 명중·착지 → 복귀 순서를 지킨다. 동작마다 잠깐 유지하는 박자를 두어 빠른 떨림으로 보이지 않게 한다.
2. 몸통·발·눈·귀의 기본 스프라이트 픽셀은 보존하면서 전체 캐릭터에 웅크림·도약·단발 반동·착지의 위치와 자세 변화를 적용한다. 공격 중 다른 이미지로 전환하거나 펫을 숨기지 않으며 화면 가장자리에서도 잘리지 않는다.
3. 먹이탄은 한 발이며 뒤따르는 잔알갱이는 장식이다. 타격 신호는 먹이탄이 명중하는 시점에 한 번만 발생한다.
4. stage 1~3은 효과의 외형만 달라지며 발사 횟수와 타격 규칙은 같다.
5. 모션 감소 설정에서는 도약·반동·볼 변형과 장식 효과를 생략하되 단일 타격 신호를 유지한다.
6. STOP, 화면 숨김, 선택 펫 변경, 전투 종료 뒤에 부푼 볼·먹이탄·명중 파편이나 공중 자세가 남지 않는다. 합성 이미지가 준비되지 않거나 그리기에 실패하면 기존 펫 이미지를 유지한다.

## Acceptance criteria

- **HAM-1:** 실제 공유 볼주머니햄 스프라이트의 세 진화 단계에서 전용 모션이 표시된다.
- **HAM-2:** 준비 때 웅크림, 도약, 발사 반동, 착지가 각각 보이며 원본 몸통·발·눈·귀의 스프라이트 픽셀은 유지된다. 탄환의 발사 지점은 이후 몸의 반동을 따라 흔들리지 않는다.
- **HAM-3:** 수동·자동 공격 모두 먹이탄 발사와 타격이 각각 한 번이며 HP·XP·적 진행에 추가 변경을 만들지 않는다.
- **HAM-4:** 진화별 탄환·잔상·명중 효과가 구분되며 정수 픽셀 단위로 표시된다.
- **HAM-5:** 모션 감소와 공격 취소 뒤 장식이 남지 않고 원래 펫 표시가 복구된다.

## API and data impact

전투 패키지의 종별 연출과 UI만 변경한다. 공개 Port, IPC, DB, 다른 패키지와 공유 PNG는 변경하지 않는다.
