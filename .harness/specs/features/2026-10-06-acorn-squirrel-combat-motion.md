# Feature specification: 도토리다람쥐 전투 모션

## Status

Approved (요청자 승인, 2026-10-06)

## Owner

전투 담당자(srkim0917)

## Problem and user outcome

도토리다람쥐(`acorn_squirrel`)의 EPIC 공격을 닌자와 숲의 특징으로 표현한다. 화면 전체의 그림자 숲, 교차하는 도토리 표창과 분신, 큰 꼬리로 닫는 도토리 봉인을 통해 강한 비술을 보여준다.

## Scope

- 수인·웅크리기 → 도약·숲 전개 → 분신 표창 → 꼬리 봉인 → 낙엽 폭발 → 복귀의 약 3.2초 모션.
- 화면 양쪽에서 가지가 솟고 나이테 영역과 금빛·민트색 낙엽이 전투 화면 전체를 채운다.
- 원본 펫의 얼굴·스카프·큰 꼬리를 활용하며 1·2단계 32×32, 3단계 48×48 프레임을 보존한다.
- 진화 단계별 2·3·4개의 그림자 분신을 만들고 여러 방향에서 도토리 표창을 교차 발사한다.

## Non-goals

- 실제 피해량, HP·XP·재화·적 진행 규칙 변경.
- 다른 펫의 모션, 공유 원본 PNG, 공개 Port·IPC·DB 변경.
- 전투 창 밖의 화면 효과.

## Domain rules

1. 본체는 원본 색과 얼굴을 유지하고 웅크리기·도약·꼬리 휘두르기를 구분한다. 그림자 분신은 반투명 민트색으로 구별한다.
2. 모든 진화 단계에서 숲과 낙엽이 전장 전체에 분포한다. 진화할수록 분신·표창·봉인이 풍성해지며 동시 표창 수는 최대 24개이다.
3. 분신·표창은 장식이다. 타격 신호는 적 주위의 도토리 봉인이 닫힐 때 한 번만 발생한다.
4. 큰 꼬리는 넓은 합성 캔버스 안에서 움직인다. 본체 얼굴을 다시 그리거나 원본 이미지 파일을 교체하지 않으며, 합성 실패 시 기존 이미지를 유지한다.
5. 본체·HP바·닫기 버튼·조작 메뉴는 효과 중에도 유지된다. 장식은 입력을 가로채지 않고 월드·카메라 좌표를 바꾸지 않는다.
6. STOP·숨김·펫 또는 단계 변경·전투 종료는 숲·분신·도약을 정리한다. 모션 감소에서는 장식을 생략하고 단일 타격을 유지한다.

## Acceptance criteria

- **SQ-1:** 실제 공유 스프라이트의 세 진화 단계에서 얼굴과 32/48px 형태가 유지되고 준비·도약·꼬리 동작이 구분된다.
- **SQ-2:** 화면 네 가로 구간에 숲·낙엽이 나타나고 분신 2·3·4개와 교차 표창, 적 주위 봉인·넓은 폭발이 순서대로 표시된다.
- **SQ-3:** 수동·자동 공격은 타격 한 번을 유지하며 HP·XP에 추가 쓰기를 만들지 않는다.
- **SQ-4:** 화면 지연에도 봉인이 명중 전에 표시된다. 공격 종료와 STOP 뒤 두 효과층과 자세가 정리되고 기본 펫이 다시 표시된다.
- **SQ-5:** 모션 감소에서도 펫과 단일 타격을 유지한다. 작은 창에서도 도약·꼬리 회전 중 본체가 화면 밖으로 잘리지 않는다.

## API and data impact

전투 패키지의 종별 모션, 스프라이트 합성과 전용 화면 효과만 추가한다. 공개 계약, 저장 형식, 다른 패키지와 공유 에셋은 변경하지 않는다.
