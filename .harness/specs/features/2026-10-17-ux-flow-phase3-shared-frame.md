# Feature specification: 동선 3단계 — 공통 틀

This specification owns the product what and why. The related implementation
plan owns the technical how.

## Status

Approved (요청자 승인, 2026-10-17)

## Owner

sh111-coder (요청자). 새 공유 패키지는 팀 전체가, 화면별 적용은 펫룸·뽑기·합성·도감·메타 담당이 리뷰한다.

## Problem and user outcome

펫룸·뽑기·합성·도감은 같은 640×420 자리에서 갈아 끼워지는 한 창인데, 화면마다 틀이 다르다(2026-10-17 동선 진단
제안 1, B2, C2).

- 다른 화면으로 가는 길이 화면마다 다르다. 펫룸은 하단 버튼 줄, 뽑기·합성·도감은 `← 펫룸` 하나, 도감만 `뽑기로 가기`가 있다.
  뽑기에서 합성으로 가려면 펫룸을 거쳐야 한다.
- 토큰 잔액은 뽑기와 합성에만, 서로 다른 자리와 모양으로 보인다. 펫룸과 도감에서는 잔액을 볼 수 없다.
- 같은 금액을 정보 패널은 `255K`, 뽑기·합성은 `255,309`로 쓴다.
- 금색 선택, 회색 비활성, 이사만루체 같은 공통 규칙을 화면마다 값으로 다시 적어서, 한 곳을 고치면 다른 곳이 어긋난다.

사용자 관점의 결과: 네 화면은 위쪽 막대가 같아 한 창처럼 보이고, 어느 화면에서든 한 번에 다른 화면으로 가며, 토큰은
언제나 같은 자리에 같은 표기로 보인다.

## Scope

### 공통 상단 바

- 펫룸·뽑기·합성·도감 창 맨 위에 높이 32px의 같은 막대를 둔다. 전투 창과 정보 패널에는 두지 않는다(결정 2·3).
- 막대 왼쪽은 탭, 오른쪽은 토큰 칩과 닫기다.

```
[펫룸] [뽑기•] [합성] [도감 NEW] [전투 ↗] [정보 ↗]          ◈ 255K  [×]
```

- 탭:
  - `펫룸 · 뽑기 · 합성 · 도감`: 누르면 같은 창 자리에서 그 화면으로 바뀐다. 지금 화면의 탭은 금색으로 표시되고 눌러도
    아무 일도 하지 않는다.
  - `전투 ↗`: 전투 창을 따로 띄운다. 지금 화면은 그대로다.
  - `정보 ↗`: 오버레이 펫 옆에 정보 패널을 연다. 지금 화면은 그대로다.
- 탭 배지:
  - `뽑기`: 1회 소환을 할 수 있으면 빨간 점(2단계 우클릭 메뉴의 `가능`과 같은 조건).
  - `도감`: 확인하지 않은 신규 발견이 있으면 `NEW`(지금 펫룸 도감 버튼의 표식을 옮긴다).
  - `정보`: 받지 않은 업적 보상이 있으면 빨간 점.
  - 빨간 점에는 접근성 이름(`뽑기 가능`, `받을 보상 있음`)을 붙인다(`design.md` §8: 색만으로 구분하지 않는다).
- 토큰 칩: 보유 토큰을 축약 표기로 보인다. 마우스를 올리면 정확한 값이 보인다.
- 닫기: 지금 창을 닫는다.
- 막대의 빈 곳을 끌면 창이 움직인다.
- 막대는 화면 내용 위에 겹치지 않는다. 창 높이를 32px 늘려 640×452로 하고, 아래 640×420은 지금 화면 그대로다.

### 화면별로 사라지는 것

막대가 대신하므로 지운다.

| 화면 | 지우는 것 |
| --- | --- |
| 펫룸 | 오른쪽 위 `×`, 하단 버튼 줄(`펫 뽑기 · 펫 합성 · 펫 도감 · 전투 · 정보`). 하단 상세가 가로 전체를 쓴다 |
| 뽑기 | 오른쪽 위 `← 펫룸`·`×`, 잔액 상자의 잔액 숫자(펫 수는 남긴다) |
| 합성 | 오른쪽 위 `← 펫룸`·`×`, `보유 토큰` 문구 |
| 도감 | 오른쪽 위 `← 펫룸`·`×` |

- 도감 빈 상태의 `펫 뽑기로 가기`, 상세의 `펫룸에서 보기`는 특정 대상으로 가는 행동이라 남긴다.

### 공통 디자인 토큰

- `design.md` §2·§3의 공통 값(글꼴, 금색, 비활성 회색, 나무·양피지 색, 글자색)을 CSS 변수 한 벌로 만든다.
- 상단 바, 네 화면의 선택 표시(금색)와 비활성 버튼(회색)이 이 변수를 쓴다.
- 각 화면의 배경 팔레트와 세계관 연출은 바꾸지 않는다(결정 4).

### 숫자 축약 통일

- 모든 화면의 토큰 금액을 축약 표기로 쓴다(요청자 결정 2026-10-17).
- 규칙은 정보 패널이 지금 쓰는 것을 그대로 쓴다.
  - 1,000 미만은 그대로 쓴다.
  - 그 이상은 `K · M · B`로 줄인다. 100 미만이면 소수 한 자리(`.0` 생략), 100 이상이면 정수다.
  - 반올림해 1,000에 닿으면 다음 단위로 올린다(999,949 → `1M`).
- 적용 대상:

| 화면 | 지금 | 바뀐 뒤 |
| --- | --- | --- |
| 뽑기 버튼 | `100,000 토큰` / `1,000,000 토큰 · RARE 이상 보장` | `100K 토큰` / `1M 토큰 · RARE 이상 보장` |
| 뽑기 부족분 | `1,000,000 토큰 · 717,331 부족` | `1M 토큰 · 717K 부족` |
| 뽑기 결과 `한 번 더` | (2단계) `100,000` | `100K` |
| 합성 재료 줄 | `재료 5 / 10 · 30,000 토큰` | `재료 5 / 10 · 30K 토큰` |
| 합성 부족 이유 | `토큰이 10,000 부족해요.` | `토큰이 10K 부족해요.` |
| 정보 패널 오늘 획득 | `+121,417` | `+121K` |
| 업적 보상 | `300,000` | `300K` |
| 상단 바 토큰 칩 | (새로 생김) | `255K` |

- 축약하면 정확한 값을 알 수 없으므로, 가능한 자리에는 마우스를 올렸을 때 정확한 값을 보인다.
- 토큰이 아닌 수(펫 수, 레벨, XP, 업적 진행 `3 / 15`, 천장 `0 / 100`)는 그대로 둔다.

## Non-goals

- 한 창 안에서 화면을 갈아 끼우는 구조(창 하나 + 화면 교체)로 바꾸는 것. 창은 지금처럼 바꾸고 자리를 맞춘다.
- 전투 창·정보 패널의 틀 변경.
- 각 화면의 배경, 연출, 세계관 색.
- 개발 도구(⚗·⚙)와 전투 모션 메뉴. 요청자 결정으로 나중에 한다.
- 토큰이 아닌 수의 표기.

## Domain rules

1. 탭 이동은 2단계의 화면 여는 규칙을 그대로 쓴다. 열려 있는 640 창 자리에서 바꾸고, 창이 두 개가 되지 않는다.
2. 상단 바는 화면이 아니라 틀이다. 어느 기능 패키지도 다른 기능 패키지를 import 하지 않고, 공통 틀은 새 공유 패키지가 갖는다
   (`.harness/rules/feature-contracts.md`).
3. 상단 바의 잔액과 배지는 메인 프로세스에서 읽는다. 잔액을 읽지 못하면 칩에 `—`를 보이고, 0으로 그리지 않는다.
4. 축약은 표시에만 쓴다. 버튼 가능 여부와 부족분 계산은 정확한 값으로 한다. 잔액 99,960은 `100K`로 보여도 1회 소환은
   비활성이고 부족분 `40`이 보인다.

## Edge and error cases

- **창을 옮기던 중 탭 이동**: 새 화면은 지금 창의 내용 영역 자리에 뜬다(`replaceWindow`의 기존 동작).
- **같은 화면 탭을 누름**: 아무 일도 하지 않는다.
- **소환·합성 연출 중 탭 이동**: 연출 중에는 탭을 비활성으로 둔다. 저장이 끝나기 전에 창이 닫히지 않게 한다.
- **잔액이 바뀜**: 막대는 창에 초점이 올 때, 1분 집계가 끝날 때, 뽑기·합성이 끝날 때 다시 읽는다.
- **전투 창이 이미 떠 있음**: `전투 ↗`는 그 창을 앞으로 가져온다.

## API and data impact

- 저장 형식·테이블·마이그레이션 변경 없음.
- 새 공유 패키지 `@pet/shell`: 상단 바, 공통 디자인 토큰 CSS, 숫자 축약 함수. 기능 패키지는 이 패키지에만 기대고 서로를
  import 하지 않는다.
- 정보 패널(`panel.js`)을 ES 모듈 스크립트로 바꿔 `@pet/shell`의 축약 함수를 import 한다. 패널 안의 기존 축약 함수는
  지운다. 화면의 모든 토큰 금액이 함수 하나를 지난다.
- 새 IPC(채널 이름은 구현 계획에서 확정): 상단 바 상태(잔액, 배지) 조회, 탭 이동, 상태 변경 알림.
- `design.md`의 펫룸 창 크기 예외(640×300 장면 + 120px 패널)에 상단 바 32px을 더해 고쳐 적는다.
