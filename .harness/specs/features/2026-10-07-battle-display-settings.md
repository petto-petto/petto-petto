# Feature specification: 설정의 전투 표시 탭

## Status

Approved

## Owner

요청자

## Problem and user outcome

설정에서 전투 애니메이션과 투명도를 조절하고, 전투 창의 외곽선까지 같은 투명도를
적용할 수 있어야 한다. 현재 투명도를 낮춰도 남는 외곽선 문제를 해결한다.

## Scope

- 설정의 알림과 기타 사이에 전투 탭을 추가한다.
- 전투 애니메이션 ON/OFF 토글과 투명도 조절을 제공한다.
- 열려 있는 전투 창에 즉시 반영하고 재진입·앱 재시작 후에도 값을 유지한다.
- 전투 중인 펫을 제외한 내용과 외곽선은 함께 투명해지도록 한다.

## Non-goals

성장·XP·정복 규칙 변경, 다른 창의 투명도 변경, 전투 애니메이션 자산 변경.

## Domain rules

- 탭 순서는 기존 설정 탭 순서를 유지하며 알림 → 전투 → 기타로 한다.
- 전체 전투 연출 기본값은 ON이다. OFF는 간소화 모드로, 제자리 기본 공격은 유지하고
  추격·카메라·큰 효과를 생략한다. XP 동기화, 적 HP, 스테이지 진행은 계속 반영한다.
- 모드를 바꾸면 현재 상태로 전환하며 이전 연출을 몰아서 재생하지 않는다.
- 투명도는 기존 전투 조절과 같은 범위인 0~100%를 사용한다.
  100%는 불투명, 0%는 완전 투명이다. 화면에 현재 값을 표시한다.
- 새 사용자의 투명도 기본값은 100%다. 기존에 저장한 전투 투명도는 보존한다.
- 전투 창에서 기존 투명도 조절을 사용해도 설정의 값과 서로 일치한다.
- 투명도는 슬라이더를 움직이는 중에도 실시간 반영한다. 조작 중 슬라이더를 다시 생성하지 않는다.
- 전투 중인 펫은 항상 불투명하게 유지하며 배경, 적, HUD, 응원 펫, 효과, 메뉴와 외곽선·창 그림자는 투명도 설정을 따른다.
- 투명도가 0%이면 전투 중인 펫만 보인다. 전투 창이 닫혀 있어도 설정을 변경할 수 있다.
- 전투 표시 설정은 펫을 바꿔도 유지하며 다른 창의 표시에는 영향을 주지 않는다.
- 저장 실패는 사용자에게 오류로 전달하며 성공으로 표시하지 않는다.

## Acceptance criteria

- 알림과 기타 사이의 전투 탭에 두 설정이 보이고 키보드로도 조작할 수 있다.
- 전체 전투 연출 OFF 시 제자리 기본 공격을 유지하고 큰 효과를 생략하며 XP 및 스테이지는 계속 갱신된다.
- 애니메이션 ON 시 현재 상태로 복귀하고 과거 연출을 재생하지 않는다.
- 설정의 투명도 슬라이더를 움직이는 중에도 열린 전투 창에 실시간 반영되며 펫은 투명해지지 않는다.
- 반투명 상태에서 외곽선·그림자만 불투명하게 남지 않는다.
- 전투창 투명도 조절과 설정값이 일치하고 앱 재시작 후 복원된다.
- 기존 저장값, 전투 창 닫힘, 완전 투명, 펫 교체, 저장 실패를 검증한다.

## Edge and error cases

설정 창과 전투 중인 펫은 전투 투명도에 영향받지 않는다.
기존 저장 상태에 애니메이션 설정이 없으면 ON으로 해석한다.
입력 범위를 벗어난 투명도는 유효한 설정으로 저장하지 않는다.

## API and data impact

전투 표시 설정을 기존 설정 저장과 전투 연동 계약에 추가한다.
기존 저장값의 호환성과 투명도 보존을 유지한다. 상세 계약은 승인 후 구현 계획에서 정한다.
