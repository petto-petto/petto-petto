# Feature specification: 정보 화면 단순화

This specification owns the product what and why. The related implementation
plan owns the technical how.

## Status

Approved

## Owner

sh111-coder

## Problem and user outcome

정보 화면(요약·사용량·실적)이 한 번에 보여주는 것이 너무 많다. 요약 한 화면에 카드 4개·숫자
7개·칩 2개·막대 2개가 있고, 사용량은 필터·잔디·도구별·모델별이 세로로 쌓이며, 실적은 타일
6개마다 소유 도메인 태그가 붙고 원장 20건이 이어진다. 칩·태그·비율 같은 잔 요소가 핵심 값을
가린다.

사용자 관점의 결과: 패널을 열면 펫과 쓸 수 있는 토큰, 이 기간에 쓴 토큰만 먼저 보인다. 더 알고
싶을 때만 `자세히`로 펼친다.

## Scope

- 정보 화면의 서브탭을 `요약`·`사용량` 둘로 줄인다. `실적` 탭을 없앤다.
- 두 탭 모두 접힌 상태와 펼친 상태를 가진다. 탭을 바꾸거나 패널을 다시 열면 항상 접힌 상태다.
- `갱신` 버튼을 서브탭 줄 오른쪽 끝으로 옮긴다. 두 탭 어디서나 같은 자리에 보인다.

### 요약

| 상태 | 내용 |
| --- | --- |
| 접힘 | 펫 카드(초상화, `이름 · Lv.N`, 칭호 글자, 경험치 막대), 사용 가능 토큰(K·M·B 단위)과 `오늘 +N`, `자세히` |
| 펼침 | 위에 더해 **함께한 기록** 6칸 — 사용한 토큰, 함께한 시간, 뽑은 횟수, 보유 펫, 도감(`보유/전체`), 업적(`해제/전체`) — 과 `접기` |

### 사용량

| 상태 | 내용 |
| --- | --- |
| 접힘 | `사용한 토큰` 카드 하나 — 큰 숫자(K·M·B)와 같은 줄에 기간 필터 `전체 / 오늘 / 주 / 달`, 도구별 막대와 토큰 수, `마지막 갱신`. 그리고 `자세히` |
| 펼침 | 위에 더해 **모델별**(상위 5개, `전체 N개 모델 보기`)과 **최근 12주** 잔디, `접기` |

- 기간 필터 기본값은 `전체`다. 필터 선택은 패널이 열려 있는 동안만 기억한다(현행 유지).

## Non-goals

- 설정·업적 화면 변경.
- 도메인 규칙·집계·저장 형식 변경. 화면 모델에서 필요한 값만 다시 고른다.
- 뽑기·합성·전투 이벤트 수집과 업적 판정 변경. 화면에서 타일을 뺄 뿐이다.
- 코인 원장 목록. 사용량 보상이 1분 집계마다 한 건씩 쌓여 최근 몇 건이 늘 `사용량 보상`으로
  채워지므로 요약에 두지 않는다. 코인 흐름은 `오늘 +N`이 보인다.
- 뽑은 횟수의 실제 연결. gacha 도메인이 아직 대역(`StubGacha`, 항상 12)이라 그 값을 그대로
  보인다. gacha 연결 작업에서 바꾼다.

## Domain rules

- **항상 접힘으로 시작**: 펼침 여부는 저장하지 않는다. 서브탭 이동과 패널 재진입에서 접힌다.
- **단위 축약**: 화면의 큰 수는 한 함수로 줄인다. 1,000 미만은 그대로, 이상은 K·M·B 이며
  100 미만은 소수 한 자리(`.0` 생략), 100 이상은 정수다. 반올림으로 1000 에 닿으면 다음 단위로
  올린다(999,949 → `1M`). 사용 가능 토큰의 정확한 값은 마우스를 올리면 보인다.
- **칭호**: 장착 칭호가 있으면 이름 옆에 작은 글자로, 없으면 아무것도 표시하지 않는다.
- **도구별·모델별 행**: 비율(%) 숫자를 표시하지 않는다. 비율은 막대가 보여준다.
- **최근 12주 잔디**: 범례를 두지 않는다. 칸에 마우스를 올리거나 초점을 옮기면 날짜와 토큰이
  보인다(INFO-004 유지).
- **빼는 요소**: `이 기기` 칩, `칭호 없음` 칩, 요약의 오늘 관측 토큰, 실적 타일의 소유 도메인
  태그, 합성·전투·최고 레벨·획득·소비 타일, 코인 원장 목록, 잔디 범례.
- **기록 없음(5.4)**: 설치 이후 기록이 없으면 사용 가능 토큰 카드에
  `설치 이후 기록이 아직 없습니다`를 함께 보인다.
- **부분 실패(5.4·INFO-007 유지)**: 함께한 기록 한 칸(예: 뽑은 횟수, 도감) 조회가 실패해도
  그 칸만 `⚠ 조회 실패`로 두고 나머지는 보인다.
- **잔디 접근성**: 범례가 없으므로 칸마다 키보드 초점과 읽기 이름(날짜·토큰)을 둔다.

## Acceptance criteria

| 관측 가능한 결과 | 확인 방법 |
| --- | --- |
| 정보 서브탭이 `요약`·`사용량` 둘이다 | 패널 self-test — 서브탭 목록 |
| 요약 접힘에 펫 카드·사용 가능 토큰·`자세히`만 있고 스크롤이 없다 | self-test — 노드와 스크롤 여부 |
| `자세히`를 누르면 함께한 기록 6칸이 나타나고(최근 코인 없음) `접기`로 돌아간다 | self-test — 클릭 경로 |
| 서브탭을 바꿨다 돌아오면 접힌 상태다 | self-test |
| 999 → `999`, 12,480 → `12.5K`, 123,456 → `123K`, 999,949 → `1M`, 1,250,000 → `1.3M` | self-test — 패널 축약 함수를 실제 런타임에서 |
| 사용량 필터 순서가 `전체 / 오늘 / 주 / 달`이고 처음 열면 `전체`다 | self-test |
| 사용량 접힘에 모델별·잔디가 없고, 펼치면 나타난다 | self-test |
| 도구별·모델별 행에 `%`가 없다 | self-test |
| `갱신` 버튼이 두 탭 모두 서브탭 줄에 있고 기존 동작(비활성·실패 표시)을 유지한다 | self-test — 기존 갱신 버튼 검사 |
| 뽑은 횟수·도감 중 하나가 실패해도 요약의 나머지는 보인다 | 계약 테스트 — 요약 화면 모델 |
| 기록이 없는 설치에서 안내 문구가 보인다 | 계약 테스트 — `hasNoRecords` |

## Edge and error cases

- 활성 펫이 없으면 펫 카드는 `아직 함께하는 펫이 없어요`만 보이고 경험치 막대는 없다(현행).
- 사용 기록이 없으면 사용한 토큰은 `0`, 도구별은 `이 기간에 기록이 없습니다`(현행).
- 모델이 5개 이하이면 `전체 N개 모델 보기`가 없다(현행).

## API and data impact

- `@pet/meta` 화면 모델: 요약 모델에 뽑은 횟수를 더하고, 오늘 관측 토큰·`deviceLabel`·
  `completionPercent`를 뺀다. 실적 화면 모델과 `info:performance` 채널은 화면에서 쓰지 않게 되며
  제거한다.
- 기획서 `.harness/specs/meta-info-settings-achievements-design.md` 5장(5.1·5.3)과 INFO-001·
  INFO-007을 이 사양에 맞게 고친다.
- 저장 형식·다른 도메인 포트 변경 없음.
