# Feature specification: 소환·합성 소형 창

## Status

Approved — 요청자 지시: 두 화면 640×420, 타이틀바 제거, 우측 상단 X로 닫기.

## Owner

동우

## Problem and user outcome

큰 소환·합성 창을 데스크톱에서 부담 없이 사용할 수 있는 크기로 줄인다.

## Scope

- 두 창은 콘텐츠 기준 640×420의 고정 크기로 열린다.
- OS 타이틀바를 제거하고 우측 상단에 창 닫기 버튼을 제공한다.
- 소환 상단 바는 제거하고 보유 토큰은 배경 우측 상단에 표시한다.
- 소환 안내·토큰 패널과 합성 제목 영역을 드래그해 창을 이동한다.
- 소환 천장 게이지는 배경 위의 읽기 쉬운 패널로 옮긴다.
- 소환 연출, 10회 결과, 합성 재료 10장과 결과를 작은 창에 맞춘다.
- 합성 하단 패널은 180px로 압축해 배경 높이를 확보한다. 진행·완료 안내 문구는
  표시하지 않으며 오류 안내는 배경 위에 필요할 때만 표시한다.

## Non-goals

전투·펫룸 변경, 확률·비용·인벤토리 규칙 변경, 공통 디자인 규약 변경.

## Domain rules

기존 소환 및 합성 규칙을 유지한다.

## Acceptance criteria

- Electron 콘텐츠 크기가 두 창 모두 640×420이다.
- 기본 화면의 주요 버튼이 창 안에 표시된다.
- 10회 소환 결과 및 합성 결과를 확인하고 닫을 수 있다.
- 우측 상단 X로 해당 창만 닫힌다.
- 닫기 버튼은 키보드 포커스와 접근 가능한 이름을 제공한다.

## Edge and error cases

결과 및 확률 패널이 열려 있어도 창 닫기 버튼에 접근할 수 있다.
모션 감소 설정에서도 합성 결과가 무대 안에 표시된다.

## API and data impact

없음. 창 닫기는 기존 브라우저 창 닫기 기능을 사용한다.

## Open questions

없음.

## Related implementation plan

standard track: 창 옵션 → 화면 레이아웃과 닫기 이벤트 → Electron 실화면 및
상호작용 확인 → 공통 검증 → 변경 검토. 기존 package-lock.json 변경은 보존한다.
