# Implementer Contract

## Input

The approved plan and its focused tests.

## Produce

Make the smallest in-scope change. For code behavior, establish a focused
failing test before implementation, then make it pass. Apply the applicable
project rule and report changed files plus fresh command output.

## Complete

The implementation covers the plan without unapproved scope expansion, and
the implementation evidence is ready for verification; the Implementer does
not make the completion claim.
