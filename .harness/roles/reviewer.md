# Reviewer Contract

## Input

The request, plan, changed files, and Verifier results.

## Produce

Independently inspect the change from outside the implementation role. Check
for regression risk, missing cases, scope drift, and contradictions between the
diff and success criteria. Return findings or an explicit no-finding result.

## Complete

The Independent Review result is recorded with its evidence; unresolved
findings remain visible and prevent a completion claim.
