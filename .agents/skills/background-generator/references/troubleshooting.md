# 증상 → 원인 → 처방

게이트를 통과했는데 그림이 이상하면 여기서 찾는다. **확대 미리보기를 눈으로 보고
증상 이름을 먼저 붙인 뒤** 처방을 적용한다. 이름이 붙으면 고치는 건 대개 한 줄이다.
게이트 두 개가 서로 반대로 움직여서 생긴 문제는 여기가 아니라
`gate_conflicts.md`를 본다.

```bash
python3 scripts/bg_preview.py <out-dir> --out /tmp/prev.png --scale 3 --layers
```

## 형태

| 증상 (보이는 모습) | 원인 | 처방 |
| --- | --- | --- |
| **전봇대** — 줄기가 곧은 막대 | `rect`로 세움 | `tree_column`. 굽이(사인 중심선)·원통 단면·수피 결 셋이 다 있어야 나무다 |
| **납작한 리본** — 줄기가 평면 띠 | 2px 하이라이트 + 3px 그림자만 | 폭을 가로지르는 연속 감쇠(`tree_column`의 단면 밴드) |
| **안개에 녹음** — 밝은 배경에서 줄기가 사라짐 | 윤곽 없음 | `edge`로 양쪽 1px 어두운 테두리 |
| **막대사탕** — 잎 벽 위에 작은 나무가 떠 있음 | 잎덩어리 위에 나무 스탬프를 얹음 | 관통 줄기로 바꾸거나, 밑동을 낮은 덤불 띠로 가리거나, 나무를 빼고 잎 매스로 통일 |
| **잘린 기둥** — 줄기 윗면이 평평하게 잘림 | 줄기가 화면 안에서 끝남 | 화면 밖(y=0)까지 빼거나, 위에 잎을 덮어 끝을 가린다 |
| **정체불명 쐐기** — 반쯤 묻힌 삼각형 | 스탬프가 딱 절반만 가려짐 | 수관 전체가 보이게 올리거나 완전히 묻는다. 애매한 절반이 제일 나쁘다 |
| **선반** — 다리가 곧은 판 | `rope_bridge`의 `sag`가 0 | 처짐을 준다. 로프는 처져야 로프다 |
| **울타리** — 잎이 균일한 띠로 이어짐 | `foliage` 상자를 통짜로 깖 | 2~3덩어리로 끊고 사이를 비운다 |
| **톱니 잎** | 짧은 주기의 `hills`(사인) | 가까운 잎은 `fringe`나 `foliage` |
| **슬래브** — 지면이 단색 판 | `band` 사용 | `ground_plane`. 구조 엣지의 절반이 여기서 나온다 |

## 색·명암

| 증상 | 원인 | 처방 |
| --- | --- | --- |
| **평평한 잎 벽** — 로브가 많은데 입체감 0 | 로브 테두리에만 림라이트, 안쪽은 단색 | `foliage`의 `spread`로 로브 **안쪽까지** 광원 방향으로 기울인다 |
| **창백한 화면** — 전체 채도가 빠짐 | 중앙 `glow`의 반경이 너무 큼 | 중앙 기둥으로 좁힌다(rx를 폭의 1/4 이하) |
| **파란 열매** — 액센트가 점점이 튐 | `accent`의 밝은 단(2~4)을 씀 | 0~1단으로. 액센트는 색조를 넓히는 것이지 시선을 뺏는 게 아니다 |
| **유령 나무** — 원경 요소가 안개에 떠 있음 | 원경 톤이 너무 밝고 밑동이 노출 | 한 단 진하게 + 밑동을 중경에 묻는다 |
| **원경이 하늘과 붙음** | 원경 램프 인덱스가 하늘 명도와 겹침 | 인덱스를 ±2. 밝은 하늘에서 `far.1`은 특히 위험 |
| **회색 뭉개짐** | 뮤트 팔레트 | 램프를 다시 뽑는다(`bg_preset_new.py`). 눈·동굴처럼 원래 채도가 낮은 주제면 `paletteMode: cool` |
| **1px 노이즈** — 지저분한 점들 | `texture` density 과다 / speckle | 0.03 이하. 질감은 `ground_plane`·`panel`·`foliage`가 만든다 |

## 구도

| 증상 | 원인 | 처방 |
| --- | --- | --- |
| **선반 진열장** — 층이 완전히 수평 정렬 | 발판 y가 전부 같음 | 층마다 높이를 조금씩 흔든다 |
| **좌우 대칭** — 심심함 | 요소를 균등 배치 | 큰 것을 한쪽에 몰고 반대쪽은 작은 것 여럿으로 |
| **세트장** — 모든 게 화면 안에 온전히 들어옴 | 잘리는 요소가 없음 | 화면 밖으로 잘리는 전경 요소를 최소 하나 |
| **캐릭터가 기둥과 겹침** | 줄기/발판이 펫 자리를 지나감 | 그 요소의 x를 `petAnchor` 밖으로. `foliage`·`scatter_depth`는 `avoid` 지원 |

## 목록을 늘리는 법

새 증상을 만나면 **이름을 붙여 여기 추가한다.** 이름이 없으면 다음 사람이 같은 걸
처음부터 발견한다. 여기 이름이 있는 증상은 사용자에게 묻지 않고 바로 고친다 —
취향이 아니라 결함이다(SKILL.md §5-A).
