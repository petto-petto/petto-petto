# 색 변환만으로 계절을 시도한 결과

`season_autumn.png` / `season_winter.png` 는 여름 원본의 팔레트만 바꿔 만든
것이다. 가을(단풍)과 겨울(눈 덮인 잎)은 **색만으로도 꽤 읽힌다** — 상록수 숲
설정이라면 이대로 쓸 수 있는 수준이다.

쓰지 않기로 한 이유는 품질이 아니라 **낙엽수의 앙상한 가지를 만들 수 없기
때문**이다. 잎인 픽셀은 역할 배정으로 골라낼 수 있지만 잎 뒤에 가지가 그려져
있지 않아서, 지우면 그 자리가 구멍이 된다.

계절 설정을 상록수로 타협한다면 이 경로가 원본 1장으로 16장을 만든다.
`matrix.py` 가 아니라 팔레트 규칙만 추가하면 된다.
