# 전투창·펫 크기·50레벨 적 진행

## 사용자 결과와 범위

실제 앱과 데모의 전투창은 처음에 640×420px로 열리고, 사용자가 모서리를 끌어 크기를 변경한다. 최소 크기는 기존 실제 앱의 360×180px이다. 크기가 달라져도 펫은 96×96px 프레임이며, 펫과 적은 같은 바닥선에 서고 공격은 가까운 거리에서 적에게 닿는다.

적은 빨강 → 주황 → 노랑 → 초록 → 파랑 → 보라 → 파스텔 무지개 순서로 진행한다. 색상마다 소 → 중 → 대를 거친다. 전체 21단계를 모든 펫 등급이 Lv.50에서 완료한다. 등급별 공격 이펙트는 유지한다.

## 도메인 규칙

- 크기별 정복 간격은 소 2레벨 상당 XP, 중 2레벨 상당 XP, 대 3레벨 상당 XP이다. 7색 × (2+2+3) = 49레벨 상승이며 Lv.1부터 Lv.50까지 한 바퀴다.
- 공통 성장 클라이언트가 제공하는 레벨별 XP 비용으로 단계별 목표 XP를 계산한다. 현재 성장 곡선 `10 + floor(level/2)`에서는 한 바퀴가 누적 1,090 XP이다.
- COMMON·RARE·EPIC의 진행 기준과 HP 비율은 같다. 펫 자체의 레벨·XP·희귀도·성장 속도는 변경하지 않는다.
- 적 HP는 해당 단계의 남은 XP 비율이다. 단순 공격 모션은 실제 HP를 깎지 않는다.
- Lv.50 이후에도 누적 XP가 증가하면 다음 바퀴를 진행한다. 성장 곡선 끝 이후의 비용은 마지막 레벨 비용을 사용한다.
- 기존 누적 XP를 새 규칙에 대입하여 단계·HP를 복원한다. XP와 소유 펫을 초기화하거나 과거 정복 연출을 재생하지 않는다.
- 정복 연출 중에는 정복한 적의 색·크기를 유지하고, 다음 적 등장부터 다음 색·크기를 표시한다. 크기/색 수동 미리보기는 서로 독립이며 실제 진행을 변경하지 않는다.

## 검증 기준

1. 실제 앱/데모 창 생성 옵션: 640×420, 최소 360×180, 크기 조절 가능. 다른 창 옵션 변화 없음.
2. 최소·기본·큰 창의 펫 프레임 96px, 기존 발바닥 보정 유지, 공격 시 화면 밖으로 벗어나지 않음.
3. 21단계의 색/크기 순서와 모든 등급의 Lv.50 정복 완료를 경계 XP별로 검증.
4. HP 100% 시작, 경계 직전/직후, 한 번에 여러 단계 증가, 재실행 복원, Lv.50 이후 누적 XP 검증.
5. 정복/등장/수동 미리보기/투명도/등급 이펙트 회귀 검증.

## 비범위

## API·데이터 영향

공통 PetClient 계약은 유지한다. 전투 패키지 내부에서 누적 XP를 해석하는 규칙과 적 표현만 변경한다. 사용자 DB를 수정하지 않고 테스트용 데이터로 검증한다. 기존 설정 필드의 호환성은 유지하되 전투 정복 간격의 등급 차이는 제거한다.
