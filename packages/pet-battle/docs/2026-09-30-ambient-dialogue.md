## 탐색·구현

- Explorer: 이전 목록은 배우·바닥 위치에서 좌표를 계산했고, 문구는 제삼자 설명이었다. 공통 에셋에는 얼굴 좌표 메타데이터가 없었다.
- Planner: 배치·대사 RED → 현재 공통 펫 18종·단계 및 적 21색·표정의 얼굴 좌표 검증 RED → 순수 크롭 선택기·말풍선 UI → 공식 gate·격리 브라우저·독립 리뷰.
- Implementer: 상단 48px, 좌우 16px, 동일 폭 최대 240px. 각진 말풍선 꼬리와 좌/우 화자 얼굴을 붙이고, idle 첫 프레임의 눈·입 영역만 정수 배율로 표시한다. 소스가 바뀌면 기존 얼굴을 즉시 제거하고 새 이미지 로드 후 표시한다.
- 기존 독립 10~20초 주기·현재 대사 중복 방지·5개 FIFO·숨김/복귀·투명도·모션 감소·클릭 통과를 유지한다. 펫 변경은 대사를 초기화하고, 같은 적의 HP 표정 변경은 대사를 유지하면서 얼굴만 바꾼다.
