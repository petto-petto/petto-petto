# 전투 UI

## 화면

- 실제 앱과 데모 모두 최초 640×420px, 최소 360×180px로 연다. 창 모서리에서 크기를 조절할 수 있다. 호스트 수정은 승인된 전투창 옵션에 한정한다.
- 창 크기가 바뀌면 같은 바닥선, 전투 간격과 돌진 거리, 이펙트 위치, 배경 관중 위치를 재계산한다.
- 중앙 배치는 전투 화면의 최초 배치에만 사용한다. 창 크기·활성 펫·진화 에셋이 바뀌어도 현재 펫과 적의 위치를 유지한다. 가로 확대는 기존 좌우 좌표를 보존하고, 세로 변경은 새 지면의 바닥선에 맞춰 기존 깊이를 옮긴다. 축소로 영역 밖이 되거나 새 적 크기로 몸이 겹치는 경우에만 필요한 만큼 보정한다.
- resize 중에는 보행·추격 반응 시간과 진행 중인 공격 차례를 재시작하지 않는다. 활성 펫·적 단계 변경 시 이전 공격·피격 효과만 취소하고 마지막 표시 위치에서 새 전투를 이어간다. 카메라와 0.5초 추적 기록도 새 지면 좌표로 함께 보정하여 뒤늦게 옛 위치로 튀지 않게 한다. 이 위치 유지 범위는 열려 있는 전투창이며 별도 저장 데이터는 추가하지 않는다.
- 전투 펫은 창 크기와 무관하게 96×96px 프레임을 유지한다. 적의 배치 프레임과 이펙트는 128px로 분리하여 함께 축소되지 않게 한다. 좁은 창에서는 위치와 프레임 사이 여백을 조정하며, 넓은 창에서도 불필요하게 멀리 걸어가지 않도록 전투 간격을 제한한다.
- 작은 창(가로 480px 미만 또는 세로 300px 미만)은 메뉴를 상단 버튼열로 배치한다. 큰 창은 캐릭터 주변 메뉴를 유지하며 모든 버튼은 32px 크기로 조작할 수 있다.
- 펫과 적을 같은 바닥선에 배치하고 대 크기의 적을 기준으로 타격 시 닿는 거리를 사용한다.
- 전투 펫은 프레임 중앙이 아니라 대기 에셋의 실제 픽셀 하단을 바닥선에 맞춘다. 종·진화 단계별 투명 여백만 보정하며 96px 크기는 유지한다. 공격 중에도 대기 에셋의 발 기준을 유지하고, 창 크기가 바뀌면 새 바닥선에 맞춰 배치한다.
- 2D 도트, 아기자기하지만 어두운 숲·폐허·성소 분위기를 사용한다.
- 적 색이 바뀌면 v2 대응 배경이 함께 바뀐다.
  - 빨강·주황·노랑: 버섯 숲
  - 초록·파랑·보라: 수정 폐허
  - 무지개: 별빛 성소

## 프로토타입 조작

- 펫 클릭: 시작, 중지, 공격, 성장, 등급별 공격 효과
- 적 클릭: 맞기, 처치, 등장, 복귀, 소·중·대 크기, 7색, HP별 표정
- 투명도 슬라이더: 배경, 적, 적 HP 바를 함께 조절
- 정복 후 자동으로 다음 적 등장. 오버레이 클릭은 처치 연출 생략용
- 모션 감소: 애니메이션 시간을 최소화하되 상태 변화는 유지

## 표현 규칙

- 적 표정 에셋은 v2 기준으로 `평온`, `걱정`, `지침`을 분리한다.
- 무지개 적은 [원본 파스텔 5색](2026-09-29-rainbow-palette.md)의 분홍·레몬·민트·하늘·라일락과 불규칙한 얼룩 배합을 유지한다. 기본 팔레트의 색상·명도를 바꾸지 않고 채도만 원안의 90%로 낮춘다. 명암은 빨강~보라 적과 같은 원본 그림자 강도를 적용하며, 황토색·청록·회보라 같은 대체 팔레트로 재선정하지 않는다. 세 표정의 눈·윤곽·크기는 유지한다.
- HP 70% 초과는 평온, 35% 초과는 걱정, 나머지는 지침을 사용한다.
- 펫 등급은 적의 외형을 바꾸지 않는다. COMMON/RARE/EPIC은 공격 이펙트만 점점 화려해진다.
- 크기 버튼은 크기만, 색상 버튼은 색상과 연결 배경만 바꾼다.
- 실제 적은 각 색마다 소(56px) → 중(64px) → 대(80px) 높이로 자동 변경된다. 크기 버튼은 현재 실제 크기의 다음 크기부터 미리보기한다. 복귀하면 실제 단계의 크기와 색으로 돌아간다.
- 펫은 적과 이펙트보다 높은 레이어에 표시하며, 공격 프레임과 이동 좌표를 v2 도트 규격으로 제한한다.

## HP 바 색상·XP 연출

- HP 테두리·숫자·초록 채움 면은 움직이지 않는다. 떨림과 5단계 틱 감소를 폐기한다. 자동 전투 중 기존 초록 그라데이션과 역방향 그라데이션의 농도만 3.6초 주기로 연하게 → 진하게 → 연하게 부드럽게 변화한다. 타격마다 색 주기를 재시작하지 않는다.
- 채움 오른쪽 **최대 2px·현재 폭의 25% 이하**에 어두운 트랙색 도트가 살짝 깎이는 효과만 둔다. 최대 불투명도는 0.28이다. 노랑·빨강 소멸 띠, 밝은 잔상, 비산하는 파편은 사용하지 않는다. 수동 `공격`·`맞기`의 끝 효과는 0.6초다.
- 실제 XP가 그대로면 HP 길이·끝 위치는 그대로다. 전투 모션으로 가짜 HP를 깎거나 XP를 생성하지 않는다.
- 저장된 누적 XP가 늘어 실제 HP가 줄면 **현재 표시값 → 최신 실제 값**을 0.7초 동안 연속 보간한다. 레벨업을 기다리지 않으며, 갱신이 겹쳐도 현재 표시값에서 이어가고 목표보다 더 깎지 않는다. 실제 값까지 수렴한 뒤에는 폭을 고정한다.
- 같은 적의 실제 0%는 숫자·정복에 즉시 반영한다. 채움은 기존 처치 연출 안에서 0.7초 이내 0으로 내려간다. 다음 적·펫 변경·재연결은 새 HP로 즉시 표시한다. 같은 적과 싸우는 중 펫 그림만 진화하면 보간을 유지한다.
- STOP·메뉴 전환·창 숨김·모션 감소는 장식을 끄고 실제 길이에 맞춘다. 멈춘 상태에서 새 실제 XP가 도착하면 감소를 표시하며, 직접 누른 맞기 미리보기도 허용한다. STOP을 다시 누르면 진행 중 효과를 즉시 취소한다.
- 기존 투명도와 화면 프레임 루프를 사용한다. HP 전용 타이머·추가 폴링·저장 데이터 변경은 없다. 공통 XP 입력 조건은 `token-growth-integration.md`를 따른다.

## 지면 전투·카메라

- HP 60% 초과: 펫이 후퇴하는 동안 적이 더 빠르게 따라간다. 적은 뒤로 걷지 않는다.
- HP 25% 초과~60%: 적이 느리게 후퇴하고 펫이 따라간다. 펫은 뒤로 걷지 않는다.
- HP 0% 초과~25%: 적이 앞 구간보다 더 먼 곳을 목표로 훨씬 느리게 후퇴하고 펫이 따라간다. 정확히 60%는 두 번째, 정확히 25%는 세 번째 구간이다.
- 펫과 적은 각자의 속도·좌표·발걸음으로 독립적으로 움직인다. 상대가 이동을 끝낼 때까지 기다리지 않으며 동시 보행을 허용한다. 두 캐릭터를 같은 보간값으로 묶거나 대기 상대를 밀지 않는다.
- 추격자는 후퇴 시작 후 **0.6초** 반응 여유를 두고 출발한다. 후퇴 목표 거리는 기존의 1.5배(기본 창 약 46px, 빈사 적 약 74px)이며 실제 거리는 화면 경계와 접촉 시점에 제한된다. 다음 교전에서도 같은 여유를 적용하여 몇 발짝 만에 다시 공격하지 않게 한다. 반응 시간이 끝나고 사거리에 들어오면 즉시 공격하며, 화면 끝에서 최소 이동 거리를 강요하지 않는다. 공격·내려찍기 재생 속도와 HP별 보행 속도는 그대로 유지한다.
- HP 경계는 보행 중이면 즉시 적용하고, 공격 중이면 현재 공격 교환이 끝난 뒤 적용한다. 화면 끝에서는 후퇴 목표를 제한하며 방향을 반대로 돌려 원위치로 보내지 않는다.
- 후퇴 방향만 HP 구간에 따라 고정한다. 지면 안에서 무작위 중간 목표점을 골라 완만한 곡선으로 움직이고, 추격자는 움직이는 상대를 따라간다. 정해진 시간표나 고정 주기 대신 거리로 접근 완료를 판단하며 매번 시작 위치로 돌아가는 보행은 없다.
- 가까워지면 보행을 멈추고 `펫 타격·공격 회복 → 적 웅크리기·도약·내려찍기·공격 회복`을 진행한다. 공격 차례는 한 번에 한 캐릭터만 가진다. 상대는 대기하거나 피격 반응만 표시하며 동시에 공격하지 않는다. 이후 현재 위치에서 새 후퇴·추격을 이어간다.
- 사거리는 캐릭터 몸이 겹치지 않는 접촉 거리에서 추가 간격 24px 이내, 바닥 깊이 차 8px 이내다. 멀리 있으면 공격 시간이어도 공격 모션·허공 타격·도약을 실행하지 않는다. 공격 중에는 둘 다 걷지 않는다.
- 펫의 공격 회복과 적 피격 반응이 끝난 뒤 적이 공격 준비를 시작한다. 적 공격 중에는 펫 공격 시트·검 이펙트를 끄고, 펫 공격 중에는 적 내려찍기 이펙트를 끈다. 적 착지에는 충격파·먼지, 펫에는 짧은 피격 반응을 표시한다. 펫 체력은 만들지 않는다.
- 적은 제자리에서 뛰지 않고 펫 방향으로 수평 이동하며 도약한다. 펫 바로 앞의 같은 지면에 내려찍되 몸을 겹치거나 관통하지 않는다. 짧은 돌진 반동·착지 후 자세 회복은 공격 교환에 포함하며 별도의 뒤로 걷기·원위치 복귀로 만들지 않는다. 다음 후퇴 여부는 현재 HP 규칙으로 결정한다.
- 내려찍기 착지점은 96px 프레임의 투명 여백이 아니라 대기 펫의 실제 불투명 픽셀 앞끝을 기준으로 잡는다. 적 착지 팽창과 이미지 여백을 포함해 코앞 약 4~10px 간격을 남긴다. 도약 중 목표를 바꾸거나 대기 펫을 밀지 않는다. 펫 공격 거리와 캐릭터 크기는 바꾸지 않는다.
- 배경의 지면 영역 안에서 좌우·깊이 이동하며 작은 창은 이동·점프 폭만 줄인다. 펫 96px은 유지하고 도약·피격 중에도 창 경계를 넘지 않는다.
- 카메라는 전투·보행 상태와 관계없이 펫의 지면 위치를 0.5초(500ms) 늦게 부드럽게 따라간다. 공격·피격·적 도약·정복 중에도 추적을 끊지 않는다. 펫이 멈추면 남은 지연 경로를 따라온 뒤 안정된다. 적 위치나 두 캐릭터의 중앙점, 발구름·점프 높이는 추적 좌표에서 제외한다. 배경·반딧불·나무 뒤 관중은 같은 좌표로 움직인다. HP 바·설정·닫기 버튼은 고정한다. 캐릭터와 배경이 화면을 벗어나지 않는 범위에서 추적한다.
- STOP·메뉴 열기 시 개체 이동과 전투 시계만 정지하며 카메라의 남은 추적은 계속한다. START는 메뉴를 닫고 재개하며, 중지 중에도 수동 모션 미리보기는 가능하다. 모션 감소 설정은 이동·점프·카메라 애니메이션을 없애고 타격 신호만 유지한다.
- 실제 HP 0이면 처치 이펙트 후 다음 적이 자동 등장한다. 미리보기의 처치 버튼은 실제 XP·정복 기록을 바꾸지 않는다.

## 펫별 공격 동작

- 동작 정의는 `src/view/pet-combat-animations.ts`에서 관리한다. 표시 중인 공통 펫의 종(`sprite`)으로 선택하며 미등록 종·신규 펫·등급별 대체 에셋은 `default` 동작을 유지한다.
- 두더지(`mole_digger`)는 세 진화 단계 모두 `굴 파기 → 지하 이동 → 적 바로 앞 지면에서 등장 → 자기 기준 왼손으로 찰싹 → 다시 잠수 → 공격 시작 위치로 지하 복귀 → 등장`한다. 적의 머리 위로 올라타지 않으며 몸통은 겹치지 않는다.
- 두더지의 공격·복귀 구간은 2.32초다. 복귀 위치는 매번 공격을 시작한 현재 위치이며 최초 화면 중앙이 아니다. 복귀를 마친 뒤에만 적이 내려찍기를 시작한다. HP별 후퇴·추격과 카메라 지연 규칙은 유지한다.
- 지면 아래로 내려간 몸은 클리핑으로 숨기고 도트 흙먼지를 표시한다. 정면 에셋의 화면 오른쪽 팔이 두더지 자신의 왼팔이다. 공통 그림을 수정하지 않고 타격 중에만 원래 팔을 가리고 연결된 전투 전용 팔·손으로 대체한다. 손 접촉 순간 기존 피격 반응을 한 번만 실행하며, 등급별 충격파는 유지하되 검 모양은 사용하지 않는다.
- `공격`과 `효과` 버튼도 같은 두더지 동작을 한 번 끝까지 보여준다. 기존 960ms 미리보기 상태가 끝나더라도 복귀를 완료하며 공통 IPC·HP·XP·저장 데이터는 바꾸지 않는다.
- STOP·메뉴 토글·창 숨김·펫 교체·적 전환은 두더지의 진행 중 동작을 취소하고 현재 지면에서 보이는 상태로 복구한다. 취소된 타격·손·흙먼지는 이어 재생하지 않는다. 창 크기만 바뀌면 안전한 범위 안에서 진행 중 동작과 원위치를 유지한다.
- 모션 감소에서는 잠수·이동을 생략하고 제자리의 짧은 손 타격 신호만 남긴다.

## 배경 관중

- 기존 왼쪽 보유 펫 줄 배치는 제거한다. 선택된 보유 펫 최대 3마리가 나무·기둥 뒤에서 머리만 좌우로 빼꼼한다.
- `숨기 → 빼꼼 → 잠깐 바라보기 → 숨기`를 서로 다른 박자로 반복한다. 클릭 영역은 만들지 않는다.
- 버섯 숲은 나무, 수정 폐허는 돌기둥, 별빛 성소는 성소 주변 나무를 사용한다. 배경 교체 시 위치도 함께 교체한다.
- 배경 원본 좌표를 실제 화면의 중앙 크롭에 맞춰 투영한다. 좁은 창에서 장애물이 잘리면 해당 관중은 숨긴다. 임의의 빈 공간으로 옮기지 않는다.
- 기존 idle 에셋의 첫 프레임 전체를 사용하고 발을 축으로 기울여 머리와 어깨를 내민다. 얼굴·목을 고정 사각형으로 자르지 않는다. 나무의 가지·장식·기둥 머리까지 원본의 계단형 윤곽을 따라 가려 몸이 장애물 뒤에 남도록 한다. 배경 그림은 변경하지 않는다.
- 관중 프레임은 이전과 같은 64·96·128px 정수 배율을 유지한다. 줄기 구간이 짧다는 이유로 펫을 축소하거나 제외하지 않는다. 기본 데모창과 넓은 창은 최대 3마리를 표시하며, 세로 크롭 시에는 화면 안에 남은 실제 나무 위치를 사용한다. 가림 경계와 발 기준점은 배경의 중앙 크롭·확대 좌표를 공유한다. 전투 펫의 96px 고정 크기와는 별도 규칙이다.
- 투명도는 배경과 함께 적용한다. 모션 감소 설정에서는 반복하지 않고 빼꼼한 모습을 유지한다.
- 적 뒤의 작은 슬라임(처치 적 관중)은 표시하지 않는다. 나무 뒤 보유 펫 관중만 유지한다.

## 큰 창 대화 말풍선

- `npm run demo --workspace @pet/battle`의 기본 640×420px 창에서도 표시한다. 콘텐츠 영역이 540×416px 이상이면 HP 바 아래(상단 48px)부터 배치하며, 왼쪽·오른쪽 창 안쪽 가장자리와 각각 16px 간격을 유지한다. 창 크기가 바뀌면 오른쪽 위치와 양쪽 폭을 다시 계산한다. 펫·적의 이동 좌표, 바닥·관중 위치와 무관하며 캐릭터 크기·전투 간격은 변경하지 않는다.
- 양쪽 목록 폭은 동일하며 최대 240px, 가운데 빈 공간은 최소 40px이다. 각 행은 36px, 행 간격은 4px이며 다섯 행이 차지하는 높이는 196px이다. 제목 없이 위에서 아래로 쌓는다. 세로가 짧은 창에서는 대사가 전투 캐릭터를 가리지 않도록 목록 전체를 숨긴다.
- 왼쪽은 각 말풍선 왼쪽에 **현재 활성 펫 얼굴**, 오른쪽은 각 말풍선 오른쪽에 **현재 적 얼굴**을 붙인다. 기존 에셋의 눈·입 영역만 정수 배율로 잘라 표시하며 몸 전체나 공격 애니메이션은 넣지 않는다. 펫 성장 단계·미리보기 외형, 적 색상·HP 표정이 바뀌면 기존 말풍선의 얼굴도 갱신한다. 새 이미지 로딩 중에는 이전 얼굴을 남기지 않는다.
- 도트 UI와 맞는 각진 말풍선과 화자 방향 꼬리를 사용한다. 펫은 양피지색, 적은 옅은 청록색 바탕에 짙은 글자를 쓴다.
- 펫·적 각각 전용 대사 20개에서 무작위 선택한다. 제삼자 설명문 대신 `친구들이 응원해주고 있어.`, `쫑긋(간지러운 귀 긁음)`, `반짝반짝. 달빛 좋아.`처럼 직접 말하는 문구를 쓴다. 각자 독립적으로 10~20초 간격에 한 줄씩 통통 나타난다.
- 각 목록은 최대 5개다. 현재 보이는 문구는 추첨에서 제외하며, 6번째 추가 시 가장 오래된 항목을 제거하고 새 항목을 아래에 넣는다.
- 실제 배고픔·피로도나 전투 상태를 판정하는 기능이 아닌 분위기 연출이다. HP·XP·성장 데이터와 연결하거나 저장하지 않는다.
- 작은 창·숨긴 창·메뉴 조작 중에는 숨기고 새 로그를 쌓지 않는다. 다시 보여도 밀린 로그를 몰아서 추가하지 않고 10~20초 뒤부터 재개한다.
- 활성 펫이 바뀌면 펫 로그를 초기화한다. 적 단계·색상이 바뀌면 적 로그를 초기화하며, 처치·등장 연출 중에는 적 로그를 숨긴다.
- 투명도는 로그에도 적용한다. 모션 감소 시 등장 애니메이션을 최소화한다. 로그는 클릭을 가로채지 않는다.
- 로그 표시 때문에 사용자가 조절한 창 크기를 자동으로 변경하지 않는다.
