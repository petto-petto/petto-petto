# 전투 UI

## 화면

- 호스트가 제공하는 실제 콘텐츠 크기에 맞춰 배치한다. 기본 창 크기를 전투 패키지에서 지정하거나 변경하지 않는다.
- 창 크기가 바뀌면 같은 바닥선, 전투 간격과 돌진 거리, 이펙트 위치, 배경 관중 위치를 재계산한다.
- 전투 펫은 창 크기와 무관하게 기존 128px 프레임을 유지한다. 적과 이펙트도 창 크기에 따라 일괄 축소하지 않는다. 좁은 창에서는 위치와 프레임 사이 여백을 조정하며, 넓은 창에서도 불필요하게 멀리 걸어가지 않도록 전투 간격을 제한한다.
- 작은 창(가로 480px 미만 또는 세로 300px 미만)은 메뉴를 상단 버튼열로 배치한다. 큰 창은 캐릭터 주변 메뉴를 유지하며 모든 버튼은 32px 크기로 조작할 수 있다.
- 펫과 적을 같은 바닥선에 배치하고 대 크기의 적을 기준으로 타격 시 닿는 거리를 사용한다.
- 2D 도트, 아기자기하지만 어두운 숲·폐허·성소 분위기를 사용한다.
- 적 색이 바뀌면 v2 대응 배경이 함께 바뀐다.
  - 빨강·주황·노랑: 버섯 숲
  - 초록·파랑·보라: 수정 폐허
  - 무지개: 별빛 성소

## 프로토타입 조작

- 펫 클릭: 시작, 중지, 공격, 성장, 등급별 공격 효과
- 적 클릭: 맞기, 처치, 등장, 복귀, 소·중·대 크기, 7색, HP별 표정
- 투명도 슬라이더: 배경, 적, 적 HP 바를 함께 조절
- 정복 후 오버레이 클릭: 처치 연출 생략 또는 다음 적 생성
- 모션 감소: 애니메이션 시간을 최소화하되 상태 변화는 유지

## 표현 규칙

- 적 표정 에셋은 v2 기준으로 `평온`, `걱정`, `지침`을 분리한다.
- HP 70% 초과는 평온, 35% 초과는 걱정, 나머지는 지침을 사용한다.
- 펫 등급은 적의 외형을 바꾸지 않는다. COMMON/RARE/EPIC은 공격 이펙트만 점점 화려해진다.
- 크기 버튼은 크기만, 색상 버튼은 색상과 연결 배경만 바꾼다.
- 펫은 적과 이펙트보다 높은 레이어에 표시하며, 공격 프레임과 이동 좌표를 v2 도트 규격으로 제한한다.

## 배경 관중

- 기존 왼쪽 보유 펫 줄 배치는 제거한다. 선택된 보유 펫 최대 3마리가 나무·기둥 뒤에서 머리만 좌우로 빼꼼한다.
- `숨기 → 빼꼼 → 잠깐 바라보기 → 숨기`를 서로 다른 박자로 반복한다. 클릭 영역은 만들지 않는다.
- 버섯 숲은 나무, 수정 폐허는 돌기둥, 별빛 성소는 성소 주변 나무를 사용한다. 배경 교체 시 위치도 함께 교체한다.
- 배경 원본 좌표를 실제 화면의 중앙 크롭에 맞춰 투영한다. 좁은 창에서 장애물이 잘리면 해당 관중은 숨긴다. 임의의 빈 공간으로 옮기지 않는다.
- 기존 idle 에셋의 첫 프레임 전체를 사용하고 발을 축으로 기울여 머리와 어깨를 내민다. 얼굴·목을 고정 사각형으로 자르지 않는다. 장애물 쪽 절반을 가려 몸이 나무·기둥 뒤에 남도록 한다. 배경 그림은 변경하지 않는다.
- 관중 프레임은 배경 확대율에 따라 64·96·128px 정수 배율로 표시한다. 가림 경계와 발 기준점은 배경의 중앙 크롭 좌표를 공유한다. 전투 펫의 128px 고정 크기와는 별도 규칙이다.
- 투명도는 배경과 함께 적용한다. 모션 감소 설정에서는 반복하지 않고 빼꼼한 모습을 유지한다.
- 오른쪽 처치 적 최대 3마리, 처치 이력이 없을 때 숨기는 규칙과 전투 펫 128px 크기는 유지한다.

## 큰 창 분위기 로그

- `npm run demo --workspace @pet/battle`의 기본 640×420px 창에서도 표시한다. 테두리를 제외한 636×416px 안에서 펫 왼쪽과 적 오른쪽에 각 150px 이상의 읽기 공간을 확보한다. 더 넓고 낮은 창도 콘텐츠 높이 288px 이상이며 양쪽 공간이 충분하면 표시한다. 캐릭터 크기·전투 간격은 변경하지 않는다.
- 펫·적 각각 전용 문구 20개에서 무작위 선택한다. 각자 독립적으로 10~20초 간격에 한 줄씩 통통 나타난다.
- 각 목록은 최대 5개다. 현재 보이는 문구는 추첨에서 제외하며, 6번째 추가 시 가장 오래된 항목을 제거하고 새 항목을 아래에 넣는다.
- 실제 배고픔·피로도나 전투 상태를 판정하는 기능이 아닌 분위기 연출이다. HP·XP·성장 데이터와 연결하거나 저장하지 않는다.
- 작은 창·숨긴 창·메뉴 조작 중에는 숨기고 새 로그를 쌓지 않는다. 다시 보여도 밀린 로그를 몰아서 추가하지 않고 10~20초 뒤부터 재개한다.
- 오른쪽 처치 적 관중이 있으면 그 위에 로그를 배치한다. 관중과 로그 5줄이 모두 들어갈 높이가 부족하면 로그를 숨긴다.
- 활성 펫이 바뀌면 펫 로그를 초기화한다. 적 단계·색상이 바뀌면 적 로그를 초기화하며, 처치·등장 연출 중에는 적 로그를 숨긴다.
- 투명도는 로그에도 적용한다. 모션 감소 시 등장 애니메이션을 최소화한다. 로그는 클릭을 가로채지 않는다.
- 창 크기 조절 허용 여부는 호스트 앱 영역이며 이 기능에서 수정하지 않는다.
