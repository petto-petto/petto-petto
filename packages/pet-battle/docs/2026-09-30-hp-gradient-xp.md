# HP 그라데이션·실제 XP 표시 설계

- Track: standard. Seed: 승인된 `battle-ui.md` HP 표시와 `battle-system.md` 누적 XP 규칙, 사용자의 떨림 폐기·작은 도트 끝·실시간 XP 보간 요청.
- 성공 기준: 바·숫자·채움 위치 고정, 잔잔한 초록 그라데이션, 오른쪽 최대 2px 도트, 레벨 내 실제 XP 증가에 따른 연속적인 HP 표시.
- 비범위: 공통 성장 저장·토큰 환산, 다른 패키지·호스트·DB·에셋, HP 계산·정복 기준 변경, 원격 push.

## 데이터 경로와 한계

`PetClient.totalXp → PetBattleIntegration → OwnedPetBattleGateway → Rust HP → 화면 보간`

- 기존 GET_STATE는 약 80ms 간격으로 요청한다. 진행 중인 요청이 있으면 중복 조회를 건너뛴다. 전투 전용 폴링을 더 만들거나 존재하지 않는 구독 API를 가정하지 않는다.
- Rust는 레벨업 이벤트가 아니라 저장된 누적 XP로 `1 - 현재 구간 XP / 목표 XP`를 계산한다. 예: Lv.1의 0 → 1 → 2 XP에서 첫 적 HP는 100 → 95.238 → 90.476%다.
- 현재 오버레이 성장 저장은 별도 `pet_profiles` 경로다. 공통 `PetClient.updateGrowth`로 반영하는 생산 호출부가 없어, 오버레이 화면의 XP가 전투에 자동 전달된다고 보장할 수 없다. 성장 담당자가 공통 클라이언트에 저장한 뒤 다음 조회 또는 `syncActivePet()`으로 반영하는 연결이 필요하다.
- 공통 포트가 제공하는 저장 XP만 사용한다. 토큰 통계나 저장 전 부분 XP를 전투에서 추정하지 않는다. 같은 저장값을 다시 읽거나 알림이 중복돼도 XP를 가산하지 않는다. HP 미리보기는 실제 XP 표시와 구분한다.

## 표시 설계

- 테두리·숫자·초록색 면을 이동시키는 떨림과 5단계 감소를 폐기한다. 실제 XP가 그대로면 채움 폭은 변하지 않는다.
- 기본 짙은 초록 → 연한 초록 그라데이션 위에 역방향 그라데이션을 겹친다. 자동 전투 중 3.6초 주기로 농도만 부드럽게 왕복하며, 타격마다 색 주기를 재시작하지 않는다.
- 오른쪽 내부 최대 2px·현재 채움 폭의 25% 이하만 어두운 트랙색 도트로 살짝 깎이는 듯 표현한다. 최대 불투명도 0.28, 노랑·빨강 띠·밝은 잔상·파편 비산은 없다. 수동 맞기·공격은 0.6초의 작은 끝 효과만 재생한다.
- 새 실제 HP가 도착하면 현재 표시값에서 0.7초 동안 연속 보간한다. 중간에 XP가 다시 늘면 그 순간의 표시값에서 최신 목표로 이어가며 증가 방향 튐·목표 이하 감소·임의 HP 소모는 없다.
- 같은 적이 실제 0%가 되면 도메인의 정복·숫자는 즉시 반영하고, 채움만 처치 연출 안에서 0.7초 이내 0으로 수렴한다. 다음 적·다른 펫·재연결은 새 실제 값으로 즉시 표시한다. 진화 이미지 변경만으로 같은 적의 보간을 끊지 않는다.
- STOP·메뉴 전환·창 숨김·모션 감소는 장식을 끄고 실제 값에 맞춘다. 이미 멈춘 상태에서도 실제 XP 갱신은 표시하며, 명시적 STOP은 진행 중 효과를 취소한다. 새 타이머 없이 기존 프레임 루프를 사용한다.

## 검증 계획

- Explorer: 현재 XP 경로는 레벨 내 변화를 이미 전달하며, 5단계 양자화·1~2px 면 이동·12px 노랑/빨강 끝 효과가 기존 UX의 원인이다.
- Planner: HP 순수 모델·CSS 계약 RED → 연속 보간/농도·도트 UI → 실제 Rust+읽기 전용 PetClient 통합 → 공식 gate → 격리 브라우저 → 독립 리뷰.
- 경계: 반복 갱신·중복 XP·0%·낮은 HP·펫/적 변경·타이머 역행·긴 숨김·STOP·미리보기·모션 감소·투명도.
- 기존 사용자 작성 `2026-09-29-battle-hp-chip-effect.md` 초안은 수정하지 않는다. 최신 동작 기준은 `battle-ui.md`에 반영한다.
