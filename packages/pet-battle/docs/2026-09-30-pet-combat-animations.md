# 펫별 전투 애니메이션

## 상태

Completed · 2026-09-30 사용자 승인·구현·검증 완료 · `work` standard 트랙.

전투 패키지 안에서만 작업한다는 사용자 지시에 따라 이 설계를 `packages/pet-battle/docs/`에 둔다.

## 결정 담당

사용자.

## 목적

현재 오버레이로 선택된 펫에 맞는 전투 동작을 표시한다. 전용 동작이 없는 기존·신규 펫도 현재 기본 전투를 정상 재생한다.

## 범위

- 전투 애니메이션 정의를 새 파일 하나에 모은다. 예정 파일: `src/view/pet-combat-animations.ts`.
- `default`: 현재 이동·공격 동작을 유지한다. 등록되지 않은 종은 자동 적용한다.
- `두더지`: 땅 파기 → 잠수·지하 이동 → **적 바로 앞 지면에서 등장** → 펫 자신의 왼손으로 찰싹 → 재잠수·지하 복귀 → 원위치에서 등장. 자동 전투 중 반복한다. 적 위로 올라타거나 머리 위로 솟지 않는다.
- 활성 펫이 바뀌면 해당 펫의 동작으로 교체한다. 이름·별명·등급이 아니라 펫 종으로 구분한다.
- 자동 전투와 수동 `공격` 미리보기에 같은 동작을 적용한다. 수동 미리보기는 한 번 재생한다.

## 제외

펫룸·메인 오버레이·DB·공통 Client·공통 펫 에셋의 수정, HP·XP 규칙 변경, 다른 종의 신규 전용 동작, 크기·배경·팔레트 변경.

## 동작 규칙

- 두더지의 원위치는 매 공격 사이클을 시작한 지면 위치다. 최초 창 실행 위치로 계속 되돌리지 않는다.
- 잠수는 단순 투명화나 가로 미끄러짐이 아니라 땅으로 들어가는 동작과 도트 흙먼지로 보인다. 지하 이동 중 몸은 지면 위에 남지 않는다.
- 왼손은 화면의 왼쪽이 아닌 펫 신체 기준이다. 타격 순간에 손동작·적 피격·등급별 효과를 맞춘다. 기존 검 효과로 손동작을 대체하지 않는다.
- 왼팔은 **현재 진화 단계의 원본 에셋에 있는 팔·발톱 픽셀**을 그대로 움직인다. 별도 CSS 주먹·새 팔을 덧붙이거나 원본 팔을 늘리지 않는다. 얼굴·몸통·반대 팔과 원래 색은 유지한다.
- 한 공격에서 피격은 한 번만 발생한다. 기존의 동시 공격 금지 규칙은 유지한다.
- 두더지의 공격·복귀 구간만 전용 동작으로 대체한다. 다른 펫의 HP별 후퇴·추격, 적 내려찍기, 카메라 0.5초 지연은 유지한다.
- 공격 모션으로 실제 HP·XP를 임의로 변경하지 않는다.

## 완료 기준

1. 전용 동작이 없는 펫과 새 종은 기존 `default` 전투를 재생한다.
2. 두더지는 모든 진화 단계에서 지정 순서를 반복하고, 원위치로 돌아온다.
3. 펫 선택 변경 후 이전 펫의 동작·흙먼지·손 잔상이 남지 않는다.
4. 최소 360×180, 기본 640×420, 큰 창 및 재생 중 크기 변경에서도 화면 이탈·몸통 겹침이 없다.
5. `STOP`, 메뉴 열기, 정복·다음 적 생성, 창 숨김으로 중단될 때 지하에 갇히거나 타격을 중복 재생하지 않는다.
6. 모션 감소 설정에서는 잠수·이동·도약을 생략하고 최소 타격 신호만 표시한다.

종 선택·시간 구간·중단·경계 단위 테스트, 실제 렌더러 시각 검증, 공통 포맷·타입·전체 테스트로 확인한다.

## 경계·오류

- 알 수 없는 종이나 전용 동작 조회 실패는 `default`로 처리한다.
- 활성 펫이 없으면 동작을 시작하지 않는다.
- 창 축소로 원위치가 영역 밖이 되면 새 화면의 안전한 지면 좌표로 보정한다.
- STOP·펫 변경·적 정복 시 중단된 공격을 뒤늦게 재생하지 않는다.

## API·데이터 영향

전투 패키지 내부 표현 로직만 변경한다. 기존 Client 입력, 저장 형식, 마이그레이션은 변경하지 않는다.

## 승인 근거

사용자: “적 위로 > 적 바로 앞 지면으로 나와 때리는 뜻임. 두더지 작업 진행.”

## 구현 계획

1. 종 식별은 공통 Client의 `activePet.sprite`를 사용한다. `mole_digger`만 전용 프로필이고 그 외는 `default`다.
2. 새 애니메이션 모듈에 기본/두더지 타임라인·좌표·지면 잠수·왼손 동작을 모은다. Arena가 공격 차례·화면 경계·카메라를 계속 소유한다.
3. 수동 두더지 공격은 전투 렌더러의 단발 요청으로 같은 Arena 동작을 재생한다. 기존 960ms Rust 미리보기·공통 IPC 계약은 바꾸지 않는다.
4. 지면 클리핑·도트 흙·왼손을 전투 UI에 추가한다. 공통 에셋은 읽기만 한다.
5. 종 선택, 순서/단일 피격, 원위치 복귀, 중단/교체, 크기 변경을 RED → GREEN으로 검증한다. 실제 렌더러에서 세 진화 단계와 수동/자동을 확인한다.

## 구현 결과

- `pet-combat-animations.ts`: 종별 프로필, 기본/두더지 시간 흐름, 잠수·흙먼지·진화 단계별 원본 왼팔 픽셀 영역과 회전의 단일 정의.
- `ArenaDirector`: 2.32초 두더지 공격·복귀 후 적 차례. 수동 요청도 같은 타임라인을 한 번 재생하며 기존 위치·경계·카메라를 유지한다.
- 렌더러: 공통 두더지 에셋에만 전용 동작을 선택한다. `MoleSprite`가 현재 표시 이미지의 첫 프레임을 읽어 원본 팔만 어깨를 중심으로 회전한다. 실제 발톱·갈색 팔·윤곽선을 그대로 사용하고 몸은 96px 크기를 유지한다. 복귀·취소하면 원본을 복원한다. 이미지 로딩 중에는 이전 펫의 팔을 표시하지 않는다.
- 펫 교체 직후 남아 있는 기존 960ms 수동 공격도 무효화한다. COMMON/RARE/EPIC 모두 검 모양은 숨기고 등급별 충격파를 유지한다.
