# 시각 검수 — 그림을 보고 판단한다

## 판단 주체

| 상황 | 누가 판단하나 |
| --- | --- |
| 사용자가 있는 대화 | **사용자.** 게이트 PASS 직후 합성본을 제시하고 지적을 받는다(SKILL.md §5-A) |
| 무인 실행(스케줄·배치) | 아래 자기 채점표로 대신한다 |

수치 게이트(`bg_check`)와 요소 채점(`bg_score`)은 **"망치지 않았는가"** 까지만
답한다. 다음 결함들은 둘 다 통과한 상태에서도 남는다.

| 결함 | bg_check | bg_score |
| --- | --- | --- |
| 다층 수직 레퍼런스인데 평평한 가로 풍경 | PASS | 71점 |
| 줄기가 전봇대, 나무가 막대사탕 | PASS | 100점 |
| 화면이 창백하게 빠짐 | PASS | 100점 |
| 액센트가 파란 열매처럼 튐 | PASS | 100점 |

**수치는 하한이지 목표가 아니다.**

## 절차 (무인 실행)

```bash
python3 scripts/bg_visual.py sheet <out-dir> --out /tmp/sheet.png --scale 2 [--pet pet.png]
python3 scripts/bg_visual.py form > /tmp/visual.json
# 시트를 실제로 열어서 보고 visual.json을 채운다
python3 scripts/bg_visual.py verify /tmp/visual.json
```

시트에는 합성본, (캐릭터 합성본), 레이어별 그림이 세로로 쌓여 나온다. 레이어를 따로
보는 이유는 전경·중경·원경 분리를 합성본만으로 판단할 수 없어서다.

**근거(evidence)에는 그림에서 본 것을 쓴다.** 게이트 결과를 옮겨 적지 않는다.

## 채점표 (100점)

| 항목 | 배점 | 보는 것 |
| --- | --- | --- |
| 레퍼런스 공간 구조 반영 | 20 | 다층 수직 레퍼런스가 평평한 가로로 나왔으면 0점. 레퍼런스가 없으면 말로 요구한 구조 기준 |
| 전경·중경·원경 분리 | 15 | 실눈을 뜨고 봤을 때 세 덩어리로 갈라지는가 |
| 캐릭터 자리·발판 가독성 | 15 | 어디에 서고 어디로 갈 수 있는지 설명 없이 보이는가 |
| 색이 선명하고 풍부한가 | 15 | 회색기가 낀 뮤트면 감점. 눈·동굴처럼 원래 채도가 낮은 주제는 색조·명도로 살아 있으면 만점 |
| 레이어별 톤 차이로 생긴 깊이감 | 15 | 뒤로 갈수록 옅어지는 흐름이 보이는가 |
| 형태·색의 변화 | 10 | 같은 스탬프가 일정 간격으로 복사돼 보이면 감점 |
| 도트 표현 충실도 | 10 | 픽셀 격자가 일관되고 팔레트가 제한적인가. 안티앨리어싱·노이즈 뭉개짐이 있으면 감점 |

**통과는 80점.** 항목 하나가 배점의 60% 미만이면 총점이 넘어도 그 영역을 결과
보고에 '부족한 영역'으로 적는다.

## 자기 채점의 한계

같은 주체가 만들고 채점하면 후하게 준다. 그래서 **사용자가 있으면 자기 채점을 하지
않는다.** 무인 실행에서 혼자 채점할 때는 시트를 실제로 열어 보고 나서 채운다.
열지 않고 채우는 건 채점이 아니다.

## 사용자에게 제시할 때

- **확대본을 첨부한다**(`bg_preview.py --scale 3` 또는 `bg_visual.py sheet`).
- 세 줄로 쓴다: 무엇을 넣었는지 / 게이트 결과 / 어디가 마음에 안 드는지 물어보기.
- **고칠지 말지 애매한 것은 고치지 말고 그 줄에 적어 함께 묻는다.**
- 지적받은 것만 고친다. 지적 없는 곳을 "겸사겸사" 바꾸지 않는다.
